# 四步离线回归基线

2026-10-31。全部为当前暂估 MuJoCo 模型；不打开真实串口，不据此宣称实机精度。

执行 `python -m slai_console.regression --output tmp/console_release/2026-10-31`。
采用固定 1 ms 仿真步长，每 20 ms 采样；原始数据为 `regression.csv`，判据/参数/结果为 `regression.json`。

| 步骤 | 操作 | 通过判据 | 本次观察值 |
|---|---|---|---|
| 零位 | 新建模型 | 四轴 max(abs(q)) ≤ 1e-12 rad | 0 rad |
| 单轴 | 零位预览 J2=45°；通过网关后执行 3 秒最小跃度目标 | 预览不动模型、不改目标；插补结束后四轴最大误差 <0.3°，在限定仿真时间内收敛 | 首次通过约 0.074881° |
| 轨迹 | 两路点 [10,30,5,-10]° → [0,0,0,0]°，每段 3 秒 | 完整计划被票据和审计绑定；最终四轴最大误差 <0.3° | 约 0.039175° |
| 动力学 | 明示切到比较姿态 [25,65,0,-25]°；重力浮动 2 秒，再弹簧保持并施加 +Z 8 N/0.4 秒 | 浮动漂移 <1e-6 rad；扰动位移范数 >0.01 rad；5 秒恢复后 <扰动的15% | 漂移 0；扰动约0.234930 rad；恢复约1.46e-14 rad |

比较姿态不是模型零位，实验不会重新定义软件零位。浮动零漂移来自同一暂估模型的完全重力补偿，不代表摩擦、负载和参数误差存在时的实际性能。

昨天桌面 UI 的“0.073°”是第一次触发“最大误差 <0.3°”时的日志值；采样周期随 UI 定时变化。不能要求固定 20 ms 采样也恰好得到 0.073°，不能把它写成 ±0.073° 实机定位精度。后续比较应在模型与环境指纹一致时比较曲线、收敛时间和上述明确阈值；变更模型后保留旧记录并建立新基线。
