## 已完成的控制链

1. 默认进入仿真，关节为已确认的模型零位，不自动连接串口。
2. 关节页拖动滑条只产生本地蓝色半透明目标，不改变实际角度。
3. 点击“执行到仿真”：网关检查后，使用 3 秒最小跃度目标曲线，加重力补偿的关节 PD 力矩控制。
4. 轨迹页添加/编辑 J1–J4 路点，校验模型限位、查看峰值速度估算，再执行仿真轨迹。
5. 动力学页切换弹簧保持、重力浮动、仅阻尼；可以施加 8 N / 0.4 秒仿真扰动并导出 CSV。
6. 概览、零位、轨迹、日志均保留 J5 行/列；J5 不查询、不使能、不控制。

## 实机接口的准确边界

选择“实机 · 只读”后再主动点击连接。921600 baud，转接器 CAN 模式。
该程序没有硬件运动输出 adapter，不发送使能、失能、设零、清故障或参数写入。USB2CAN 的请求只发送到电机 1–4；绝不请求 ID5。
外部工具占用 COM9 时连接会报错，不会抢占或关闭它。

实机反馈过期超过 1 秒显示 `—`，目标也不冒充反馈。三维中缺失关节保留上次姿态，并明确标注不能代表当前状态。
“软件停止”在仿真中清空轨迹并保持当前姿态；实机只读中不发送停机命令。它不是硬件急停。硬件急停回路当前未接入，状态显示未知。

## 软件零位

换算采用协议的 16 位位置字段和电机实时 PMAX：

```
encoder_rad = raw16 * 2 * PMAX / 65535 - PMAX
model_rad = direction * (encoder_rad - zero_offset_rad)
```

不能按 `16384` 编码器圈数计算。采集新零位只进入待审草稿，要求新鲜反馈、失能、速度绝对值 < 0.02 rad/s；导出 JSON 不覆盖生效映射。当前无自动应用/导入，也不写电机内部零位。

## 网关与状态机

拒绝规则按顺序：R1 非 J1–J4；R2 非仿真输出；R3 未连接/反馈过期；R4 未使能、故障或执行中；R5 空目标、重复轴、非有限值、模型限位外；R6 过期、伪造、已消费的预览票据。
预览为一次性 ticket。轨迹票据绑定完整路点及每段时长，审计记录同一份不可变计划。切页、切模式、断开、取消都会使其失效；目标越界直接拒绝，不静默裁剪。
`IDLE → PREVIEW → EXECUTING → DONE`。轨迹命令完成后误差 < 0.3° 才标为到达；控制时间使用仿真时钟。

### 六条维护不变量

以下约束来自 2026-10-30 静态复核闭环回执，适用于当前实现：

1. 确认只读线程断开成功后才提交模式变更；失败时实际模式不变、选择器回滚。
2. 新建 `Context` 显式传入 `connected/fresh/enabled`；保留默认拒绝。R3 表示状态源不可信，R4 表示可信状态下仍被禁止。
3. 执行参数必须取自已提交票据。单次关节运动与轨迹均使用 `ticket.duration`，轨迹另使用 `ticket.plan`，不能改读调用处可能已改变的局部路点。
4. 新增关节/轨迹命令入口遵循 `ticket → commit → execute`；adapter 的 busy 检查不能代替许可。仿真扰动实验另受仅仿真模式约束。
5. 新增 `#id` 按钮样式同时定义 `#id:disabled`，防止 ID 选择器覆盖禁用态。
6. `on_sample` 定义遥测进入 UI 的最小字段集；删改校验字段时同步核对 `_tick` 的全部取值点，异常反馈不能冒充有效状态。

回执原文保存在 `REVIEW_CLOSURE_20261030.md`。当前审计“接受”只表示仿真网关接收；未来实机输出必须区分“接收 / 发送 / 设备确认”，并分别保存 command_id 和失败状态。
