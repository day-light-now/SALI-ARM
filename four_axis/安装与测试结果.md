# SLAI 四轴 ROS 2 安装与测试结果

已安装 Ubuntu 24.04.5 WSL2 和 ROS 2 Jazzy，并完成四轴假硬件控制测试。

## 下次开机怎么用

1. 双击桌面 `启动SLAI四轴ROS2仿真.bat`，等待 RViz 和控制器启动。
2. 双击桌面 `SLAI四轴小幅运动.bat`。J1 目标约 10°，J2/J3/J4 约 ±5°，三秒完成。
3. 在启动窗口按 Ctrl+C 可关闭仿真。

这是 RViz 假硬件关节控制，不包含 MuJoCo 动力学，也没有连接真实 CAN。

## 验证结果

- 官方 Ubuntu 镜像 SHA256 校验通过。
- 旧 Ubuntu 26.04 已移除；完整备份保存在相邻的 `wsl_backups` 文件夹。
- `colcon build --symlink-install`：两个包均成功。
- Xacro 展开及 URDF 校验通过：5 个 link、4 个可动 joint、5 个有效网格。
- CAD 的四轴变换、旋转轴、限位及父子关系与已确认模型一致。
- `robot_state_publisher`、`ros2_control`、两个控制器和 RViz 实际启动成功。
- `enforce_command_limits=true`，运行日志确认四轴位置和速度限位已加载。
- 桌面小幅运动脚本对应的 ROS 程序实际执行成功，收到成功完成结果。
- 自动测试执行零位、小角度目标、回零；三段轨迹均成功，反馈误差均小于 0.002 rad。
- 最后一段测得角度约 `[0.000554, 0.000277, -0.000277, 0.000277]` rad，随后继续保持零位。
- `dpkg --audit` 无未完成软件包配置。

展开后的测试 URDF 与运行日志保存在 `verification` 子文件夹。
惯量暂缺，因此只适用于当前运动显示和假硬件位置测试；不能据此进行动力学或力矩计算。
WSL 的非实时调度提示，以及控制器退出时统计线程的 context 提示，不影响此次轨迹完成结果。
控制器与状态发布器正常退出；最终复测后的 RViz 未及时响应退出信号，被 launch 强制结束（退出码 -9）。
这属于图形窗口退出问题，四轴轨迹测试已在此前成功完成。
