# SLAI 桌面上位机

双击 `启动桌面上位机.vbs` 打开原生窗口。若无法启动，用 `.bat` 查看错误。

默认进入仿真，模型就是原 SLAI 的 MuJoCo 模型。拖动关节滑条只预览，再点击“执行到仿真”。轨迹和动力学实验也在此窗口中。

实机模式目前只读反馈，不发送电机运动、不改电机参数；J5 始终不查询、不使能、不控制。

源码和完整说明：`D:/CodexData/Projects/机械臂/slaihand_ros2_ws/slai_console/README.md`。
设计参考、验证截图和 DeepSeek 复核结果放在本文件夹的对应子目录。

实机只读模式下，“软件停止”没有停机权限，不能代替物理急停。

## 2026-11-02 版本切换

双击 `启动桌面上位机.vbs` 打开 **“SLAI 机械臂上位机 · 模式切换”**。同一窗口选择：

- **DeepSeek 五轴**：J1–J4 原生 MIT，J5 关闭；实验路径；J4=Kp160/Kd5/1.0，J1–J3=Kp32/Kd2/0.2。
- **Codex J4 原生 MIT**：2026-11-02 实机受支撑往返已通过；J4 单轴，已知良好基线。
- **PySide6 桌面上位机**：仿真 / 四轴只读；实机运动网关仍关闭。
- 诊断：主机 PD 受限接管、J4 保护测试。

**同一时间只允许一个模式占用 COM9。** 子程序窗口运行期间，上位机里的其他模式禁用；关闭子程序窗口后才能切换。上位机壳本身不连接串口、不使能、不发帧；每个模式自己的票据/确认仍然有效。
