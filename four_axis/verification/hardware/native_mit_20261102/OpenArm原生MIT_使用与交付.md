# OpenArm原生MIT入口（DMMC02）

入口：本目录 OpenArm原生MIT.bat。它启动独立窗口，打开时不连接串口、不使能、不回零。旧受限实机接管.bat仍为主机PD诊断入口，不能混淆。不要同时让两个程序占用COM9。

此版本按OpenArm官方MIT五字段发送q/dq/Kp/Kd/tau_ff，驱动内部执行PD。当前可选择J2、J3或J4独立台架适配，每次仅所选轴使能和控制，其余轴只监视，J5完全排除。J3和J4各有一次实机往返通过，J2待实机验证。固定Kp160、Kd5、1秒增益斜坡，当前姿态接管；原生MIT首次试验不是全臂移植验收，不代表已实现全部OpenArm功能。

必须理解：旧2Nm是主机总力矩命令限幅；本版本J2的10Nm、J3/J4的2Nm只是当前新鲜反馈状态下的请求估算中止护栏，不是驱动内部持续总力矩硬限幅。过流阈值约0.8不能直接当0.8A或连续限流；KT回读0也不能用于力矩-电流换算。未改电机KT/OC/模式/TIMEOUT/Flash/零位。若要求连续2Nm硬限幅，先不要使能，核实驱动侧限幅后另行配置。

操作：
1. 关闭达妙工具设备连接，打开本入口，点“连接·只读”。确认J1—J4当次均模式1、TIMEOUT2000、正常失能；错误时程序会拒绝接管，不会自动修改参数。
2. 先选择本轮控制轴（本轮J2），确认全臂及末端可靠支撑、所选轴起点−4°到+14°无干涉、支撑不夹住转轴、人员离开转动范围且可立即切电。
3. 只有明确接受原生MIT输出区别，才勾选对应确认。窗口未勾选时不会使能。
4. 可直接点“原生MIT 接管稳定→+10°→起点”。程序先在当前位置平滑接管，2秒后核查最近至少0.4秒的有效反馈与≤0.5°误差，通过才继续往返；失败全停，不要求先另点一次保持。
5. 保持按钮仅供单独诊断。往返每程18秒、整次最多45秒，不回软件零位；每次均重新预检、采集当前位置并检查实时稳定性。
6. 异常按停止并现场切电；UNKNOWN停止主动轮询并关闭串口，不自动重连。失败不连续重试，把结果JSON发来。
