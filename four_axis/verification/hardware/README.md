# J1 只读状态监视

用途：在 DMTool 参数读取和温度有反馈、位置显示持续为0时，独立查询并解析 J1 实际状态。

入口：`j1_monitor.py`；桌面 `SLAI_J1只读状态监视.lnk`。
使用本机 Python312 与 `C:/Users/ASUS/Documents/机械臂/tmp/slai_serial_deps` 中的 pyserial 3.5。
先在 DMTool 点击关闭设备释放串口。窗口默认 COM9，点击连接；桌面入口会自动连接。

传输依据：[达妙官方 motor-sdk u2can/DM_CAN.py](https://github.com/dmBots/motor-sdk/blob/main/Python%E4%BE%8B%E7%A8%8B/u2can/DM_CAN.py)。
发送30字节 USB 帧，接收16字节帧，支持串口分片和连续多帧。
只允许 CAN 0x7FF 上的读寄存器 0x33 和状态查询 0xCC；电机地址固定1。
先核对 RID7（Master ID=0）、RID8（电机ID=1）、RID10（控制模式）及 RID21/22/23（位置/速度/力矩映射），再解码状态。
Master ID=0 的反馈 CAN ID=0，按负载中的电机编号匹配，不当作缺失数据。

程序不包含使能、运动、写参数、设零或校准指令。断开与关窗不发送指令。
不改变电机已有状态，因此运行前应保持失能；这是读状态工具，不是急停或运动控制器。
位置为编码器坐标，未对齐机械零位。仅量化范围，不代表机械运动限位或额定安全力矩。
反馈超过1秒未更新则标记过期，清除显示值。原始日志写入工作区 tmp 下的 JSONL。

验证：`python j1_monitor.py --self-test` 校验发送白名单、分片接收、多帧、Master ID=0 和已知报文解码。
`--probe --port COM9` 仅做有限的只读硬件查询，不打开 GUI。
2026-10-10：离线检查通过；实测6个参数请求、3个状态查询，共9次请求/9次回应。
实测位置1.389906 rad，状态0，电机25°C，驱动30°C。未发送使能或运动指令。

DMTool 显示问题原因仍未确定：独立读取证明真实位置可获取，不足以证明该软件具体哪个模块有问题。
