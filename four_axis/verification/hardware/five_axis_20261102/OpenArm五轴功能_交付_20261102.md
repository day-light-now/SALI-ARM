## 2. 参照的 OpenArm 控制方法

官方 `enactic/openarm_can` commit `f340d4b808fb177e1f297af54eb55fd51c6c7c10`：

- `openarm_simple_hardware.cpp::read` 逐轴读位置/速度/力矩；
- `write` 对每个臂轴发送 MIT 五字段 `{kp,kd,pos,vel,tau}`，PD 在驱动内部；
- `on_activate` 使用 `enable_all` + `return_to_zero`；控制器有 forward position / forward velocity / joint trajectory；官方 `update_rate: 750`，CAN-FD。

Codex 的 J4 原生适配已验证五字段编码、截断量化、严格拒绝越界、坐标映射、1s 增益斜坡、当前位置接管、观测点估计护栏和四轴 FD；其文档明确“不是全臂移植”。本交付沿用这些已验证的编码/安全思路，扩展到五轴，但**没有**照搬 `enable_all`/`return_to_zero`，也**没有**把 750Hz 当成已实现。

## 4. 控制行为

- **执行位置**：驱动内部 MIT；主机发送五字段，不做主机 PD。
- **调度**：主机 100Hz（10ms），不是 750Hz；反馈年龄 ≤60ms，主机间隔 >40ms 故障。
- **使能**：当前位置接管，不自动回零；逐轴预置 MIT（kp=kd=0）→ FC → 状态 1 → 1s 增益斜坡；任一轴失败/超时 → 全部已激活轴 FD。
- **保持**：2 秒当前姿态；不声称负载保持。
- **轨迹**：1–32 个五轴路点，minjerk；逐段峰值速度 ≤0.02rad/s；到点误差 ≤0.5°/轴；总时长 1–60s。
- **速度**：需要额外的 `velocity_acknowledged`；kp=0、kd=驱动内部速度环；每轴目标 ≤0.02rad/s；时长 ≤5s；速度误差 >0.05rad/s、反馈速度 >0.2rad/s、估计护栏触发即停。
- **安全**：逐轴行程、跟随误差 ≤4°、温度 ≤50°C、反馈力矩 >2×估计护栏、请求估计 >护栏、状态异常/主机周期/反馈过期 → 取消计划、FD J1–J5 中所有 active 轴、等待新 state0；超时 UNKNOWN，不自动重连/重试。反馈速度中止逐轴：J1–J3/J5 模板 0.2rad/s，J4 用 Codex 2026-11-02 实机已测的 1.0rad/s（用户明确批准，仅原生入口；目标参考仍 0.02rad/s）。
- **停止后**：只读确认；UNKNOWN 时控制台锁定轮询，不再主动查询，必须断开现场检查。
- **配置门**：`user_confirmed=true`；J1–J4 行程不越过 `core.LIMITS`；J5 行程由标定记录给出，配置只能缩窄。
- **J5 门**：没有可用 `j5_calibration.json` 时 active_axes=(1,2,3,4)，J5 只监视；J5 的 `TIMEOUT` 必须 2000、`CTRL_MODE` 必须 1，否则拒绝。

### 6.1 复核并确认 `five_axis_config.json`

当前模板：J1 −78..198°、J2 −8..188°、J3 −88..88°、J4 −88..48°、J5 由标定；估计护栏 J1–J4 2Nm、J5 1Nm；**J4 已按 Codex 2026-11-02 实机受支撑往返（9.857°、回差 0.306°、四轴新反馈 DISABLED）对齐为 Kp160/Kd5、反馈速度中止 1.0rad/s**；J1–J3/J5 仍是 Kp32/Kd2、反馈 0.2rad/s 的未实测模板；速度 0.02rad/s；跟随 4°；温度 50°C。

**2Nm 估计护栏对整臂重力很可能偏低**，它只是“当前反馈点请求估计”的中止阈值，不是驱动硬限幅。若整臂需要更大保持力矩，必须由操作员根据机械/负载评估修改；**不要因为一次触发就盲目上调**。如果要求严格的连续力矩硬限幅，先不要使能，核实驱动侧电流/力矩限制。

### 6.2 手动标定 J5（不使能电机）

1. 五轴只读监视器连接，确认 J5 状态 0、模式 1、TIMEOUT 2000、反馈新鲜；
2. 人员离开、J5 可反驱/已失能；
3. 手动放四个位置：零点、正方向、最小安全端、最大安全端；每次点“记录”；
4. 软件推断 `sign`，检查零位在行程内、跨度足够；勾选确认；保存 `j5_calibration.json`；
5. 断开重连，确认 J5 显示“已标定”，再复核配置并确认 `user_confirmed=true`。

未完成这两步前，五轴控制台只能跑 J1–J4；J5 只监视。**不要用 OpenArm 的 J5 零位代替本机零位。**
