## 1. 年龄改为相加（每轴 driver_age + local_receipt_age）

- `Recorder._build()`：`total_age_s[i] = feedback_age_s[i] + local_receipt_age_s`，任一轴非有限/为负或 > 0.06 s 即拒绝；`capture_age_s = max(total_age_s)`，并保留 `feedback_age_s`、`local_receipt_age_s`、`total_age_s` 三个字段不混用；校验时检查 `capture_age_s` 与每轴总年龄最大值一致（1e-6）。
- 反例：driver .035 + local .035 → 总 .070 被拒绝（此前返回 .035）；新鲜样本 `capture_age_s≈.020`，大于任一驱动年龄。
- 传输时间无法界定时，文档注明总年龄只是**下界**。

## 2. 静止窗口逐帧检查（不再只看末帧）

- `_window_aggregate` 现在对**每一帧**检查：stage∈{HOLD,TRACK}、四轴 motor_state=1、每帧 total age 新鲜、前馈 α=0 且新鲜、命令 ID 一致；并记录 `all_enabled`、`fresh_all`、`ff_all_zero`、`ff_all_fresh`、`command_ids`、`max_gap_s`、`valid`、`reasons`；`motor_state` 取逐轴最小值（首帧失能时不再是全 1）。
- `collect_static` 在命令 ID 变化时**丢弃窗口重采**，不拼接两个会话；采样间隙 > 0.3 s、跨度/样本不足、任一帧不满足条件均拒绝并打印原因。
- `validate_sample`/`exclusion_reason` 对窗口的 `all_enabled/fresh_all/ff_all_zero/ff_all_fresh/max_gap_s/command_ids/valid` 全部复核。
- 反例：首帧 stage8/motor 0 的 5 帧窗口 → `all_enabled=false`、`motor_state=[0,0,0,0]`、`valid=false`。

## 3. 前馈状态时效/阶段/命令 ID

- `driver_ff` 记录 alpha、ramp、active、applied、stage、command_id、age_s；`_build` 用当前接收时间计算 age。
- 拟合资格要求：前馈状态存在、`age_s ≤ 1.5 s`（α=0 时驱动 1 Hz 刷新，阈值留余量）、`alpha == 0`、`stage` 与采样阶段一致、`command_id` 属于窗口唯一命令 ID、窗口内逐帧 `ff_all_zero/ff_all_fresh`。
- 缺失/过期/非零/阶段或命令不符 → 排除（原始保留），诊断值仍在 `diagnostics`；反例 `age_s=120` 的 12 条样本现在 INSUFFICIENT。
