# 手动调参（Kp/Kd）接口设计节点 — 第三轮

状态：**待确认驱动侧接口**。面板侧可按本文件实现；驱动侧 `src/slaihand_hardware/` 属受保护文件，本轮未改，需 Codex 实现或明确授权。

## 1. 现状（已核实）

- 驱动只有三个服务：`/slaihand/arm_supported_current_pose`、`/slaihand/stop_all`、`/slaihand/reset_disabled`；**没有**增益服务，也没有声明节点参数（`grep create_service / declare_parameter` 为空）。
- Kp/Kd 在 `CanUsbSystem::on_init()` 由 URDF 硬件参数 `kp`/`kd`（来自 `canusb_motion_policy.yaml`）读入 `policy_`，`controls()` 每周期用 `policy_.kp/kd` 组成 MIT 帧；运行期不可变。
- 因此“只保存表单”无法让参数生效；面板不能重写控制律、不能重启/重配驱动，也不能改受保护文件。

## 2. 最小驱动接口契约（建议，topic 形式，不需要新增接口包）

新增只读+请求两条 `std_msgs/Float64MultiArray` 话题（`std_msgs` 已是现有依赖）：

- 请求 `/slaihand/gain_setpoints`：`data = [seq, kp1, kp2, kp3, kp4, kd1, kd2, kd3, kd4]`（9 个数；`seq` 单调递增整数，float64 可精确表示）。
- 确认 `/slaihand/gain_state`：`data = [seq, kp1, kp2, kp3, kp4, kd1, kd2, kd3, kd4, accepted, code]`（11 个数）。
  - `code`：0 已应用；1 超范围/非有限；2 非失能或反馈不新鲜；3 重复/过期 seq；4 正被占用（使能中）。
- 驱动规则：
  1. 仅在 `stage_==DISABLED`、四轴 `disabled_observed` 且反馈新鲜、`owned_==false` 时接受；运动中/UNKNOWN 一律拒绝并回 code。
  2. 范围：`0 < Kp ≤ 160`、`0 < Kd ≤ 5`（沿用现有 MIT 接口上限，不扩大授权），四轴一次原子生效；只影响下一次使能，绝不修改运行中的 MIT 帧。
  3. 拒绝写 Flash/零位/方向/TIMEOUT/增益上限；只改内存中的 `policy_.kp/kd`。
  4. 应用后追加审计记录（AUDIT kind=GAIN，含旧值/新值/seq/时间），并发布 `gain_state` 确认；启动时也发布一次当前值（`accepted=1, code=0`）。
- 面板规则：
  1. 只在自身快照为“四轴一致 DISABLED + `feedback_valid` 新鲜 + 无操作进行中 + 非 UNKNOWN”时允许提交；提交前要求显式确认，运动中按钮禁用、服务端同样拒绝。
  2. 显示三组值：**默认值**（来自已安装 policy 的 kp/kd，缺省 160/5，只读）、**待应用值**（表单）、**实际生效值**（最近一次驱动确认的 `gain_state`，含时间与 seq）；没有确认时显示“未确认”，不把表单值当生效值。
  3. 提供恢复默认（160/5）、配置保存/载入（任务专用目录 `gains/`）、应用记录（时间、旧值→新值、seq、结果码），不写任意路径。
  4. 驱动未提供接口时（无 `gain_state`、无 ack），调参页明确显示“驱动未提供增益接口”，应用按钮禁用；不伪造生效。

## 3. 若 Codex 更倾向服务形式

用 `slaihand_hardware/srv/SetGains`（`float64[4] kp`、`float64[4] kd` → `bool accepted`、`string message`、`float64[4] kp_effective`、`float64[4] kd_effective`）更严谨；面板侧只需替换“发布请求/订阅确认”为“调用服务/读回复”，其余 UI、校验、记录、门禁不变。驱动需新增 `rosidl` 接口包或在本包生成接口。

## 4. 测试口径（接口落地后）

- 生产回调反例：非失能/反馈陈旧/UNKNOWN/运动中/超范围/非有限/重复 seq 全部拒绝且无发布；四轴不一致拒绝。
- 模拟总线（新 PTY + 隔离域 176）：驱动服务/话题真实生效；应用后 arm 的 MIT 帧 kp/kd 与确认值一致（在假驱动解码帧验证）；运动帧不被修改；默认恢复生效；应用记录落盘。
- 浏览器：表单三组值、禁用态原因、确认后提交、ack 后“实际生效值”更新、恢复默认、存档载入、日志 textContent；Edge 与候选页面截图。
- 不改速度上限（当前 0.5 rad/s）、URDF 限位、0.5° 判据、45 秒会话、停止门禁与其它保护。
