# J1至J4实机只读监视

2026-10-30。程序入口 four_axis_monitor.py；桌面启动入口位于 SLAI机械臂控制/02_实机控制_待接入/四轴实机只读监视.bat。

## 使用

1. 保持已核对的供电和CAN接线；禁止带电插拔。当前允许五台物理接入，但软件只向编号1、2、3、4发送读取请求。
2. 在DMTool点击“关闭设备”释放串口；关闭J3受限回位及其他控制程序。转接器保持CAN模式，不切换UART。
3. 打开只读窗口，选正确串口（历史COM9），点击“连接并读取四轴”。窗口打开本身不连接、不发送。
4. 等四轴参数读取完成，再检查每轴状态、角度、温度。软件角度由本地 hardware_mapping.yaml 的方向和零偏换算，不写电机内部零点。
5. 将四轴表格截图提供给助手。读取失败不代表设备必然掉线；先检查串口占用、波特率、模式、ID和线束，不自动重写编号。

## 发送边界

所有发送帧均为CAN0x7FF的标准8字节参数读取或状态查询，目标ID仅为1至4。只读寄存器包括Master ID、ESC ID、TIMEOUT、控制模式、位置/速度/力矩映射。没有参数写入、保存、清故障、校准、设零、使能或运动指令；不会向ID5发送查询或其他请求，也不会广播。

关闭或断开不发送任何命令，因此不会改变已使能电机的状态，也不构成急停。若发现已使能、故障或异常发热，不要手动转动或继续运动操作，应按现场支撑与电源切断流程处理。

软件相对角度只基于人工记录。J1/J2沿用较早记录，J3/J4为今天采集。未通过精密零位标定，也没有统一编码器回绕处理；跨圈或不合理突跳应停止解读。速度列为编码器方向，软件角度列才经过方向系数转换。

反馈超过1秒清空角度，避免旧值被当成实时读数。同一ID同一寄存器若出现不同回复，标记冲突并停止显示该轴有效角度。接收非目标ID报文只记录和忽略，不向其发送请求。TIMEOUT为电机计数值，显示不等于该轴已实测保护。

日志保存于工作区 tmp/four_axis_readonly，每次连接生成JSONL，包括每条发送与接收。8项离线测试已通过，覆盖发送白名单、J5排除、帧分片、软件映射、反馈过期、重复ID参数冲突、参数未齐不解码、断开不发命令。尚需现场验证四轴实时反馈。
