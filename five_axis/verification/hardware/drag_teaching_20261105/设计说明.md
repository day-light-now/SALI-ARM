# 网页拖动示教：设计说明（v1）

工作树 `slaihand_drag_teaching_ws`，分支 `feature/drag-teaching`，基线 `snapshot/2026-11-06-control-panel`（493cd2d）。本轮只做软件与隔离域 176 的 PTY 验证；实机串口、ROS 域 0、现有驱动/面板进程与桌面实机入口均为保留环境。

## 1. 记录所有权与数据流

- **运动仍只属于受保护客户端**：开始记录 = 启动一次既有 `--gravity-float` 自由拖动（Kp=0/Kd=5、α=1、3 秒前馈渐入、5 秒体验、既有全轴停止与失能确认）。记录不会新增使能请求、不改增益/限位/门禁。
- **记录所有权归面板后端**（`PanelBackend`）：在唯一的 `/slaihand/dynamic_joint_states` 回调里，按帧把四轴 position/velocity/feedback_age/feedback_valid/motor_state/control_state/command_id/hold_ready 与驱动运行身份（`/slaihand/runtime_identity` 的 boot_id、四个配置哈希、load_id、实际接受的 Kp/Kd/α/斜坡/reference_speed）送入 `drag_teaching.TeachingRecorder`。
- 有效窗口：仅当自由拖动渐入完成（hold_ready=1）、stage=5、四轴新鲜有效使能、command_id 与 boot_id 稳定时开始；窗口内任一帧失效、stage 变化、command_id/boot_id 变化、采样间隙超过 0.05 s 或越限，立即关闭窗口并显式标记不完整。
- 原始帧全部保留（相对单调时间、采样间隙、年龄、命令 ID），不压缩。

## 2. 停止竞态与落盘顺序

- 停止优先：`停止记录` 复用既有 `_request_stop`（停止纪元 +1、门禁锁定、SIGTERM 客户端、客户端 finally 完成 stop_all 与新失能确认），**记录不会自己调用停止服务**，也不会在停止后重启。
- 记录文件写入只在操作结束（客户端退出、停止流程完成）之后、由独立的落盘线程执行；ROS 看门狗线程不做磁盘 I/O。停止请求先于任何 `save/rename`。
- 停止/心跳丢失/UNKNOWN 期间进入的记录窗口被标记中断；门禁锁定后所有预览/执行/再记录入口保持拒绝，直到手动复位后的新 DISARMED 观测。

## 3. 轨迹表示与回放

- 教学文件保存原始帧 `(t, q, dq, age, stage, command_id)`，不降采样；`content_sha256` 覆盖 `source/quality/samples`，文件独占创建、严格 schema（`slaihand_drag_teaching/1`），名称只作界面显示，文件名只用 16 位十六进制 ID。
- 回放 = **接近段 + 原始记录重定时**：
  - 接近段：从执行时实际参考起点到记录首帧，五次多项式，默认峰值 0.5 rad/s，最短 0.6 s；
  - 记录段：所有原始采样点按 `t/factor` 重新计时（factor 默认 0.5），JTC 在相邻记录点之间线性插值；所有原始采样点都被精确经过，没有 12 路点简化。
  - 误差界：记录段误差只来自“原始 100 Hz 采样 + 相邻点线性插值”，预览给出各关节二阶差分/8 的弯曲界（度）与最大相邻采样间隔；重定时只改变时间不改变几何。
- 硬约束：回放轨迹峰值参考速度 ≤ 1 rad/s（取规划器上限与驱动实际 `reference_speed_rad_s` 的较小者），全部关节在 J1 −80°～200°、J2 −10°～190°、J3 −90°～90°、J4 −50°～90°；总时长（接近+记录）≤ 169 s。速度比例 0.1～1.0，默认 0.5，界面明确显示；记录峰值 × 比例超过上限时预览直接拒绝并提示所需比例。
- 回放走 `commission_supported_trial.py --teaching-plan`：正常位置控制（Kp=160/Kd=5、α=0.1 的常规使能路径），复用 arm→hold→JTC→结果→stop_all→新失能确认；**绝不带 `--gravity-float`**，不会沿用零刚度模式。冻结的播放规格写入本次操作目录，客户端再校验一次 schema/限位/速度/单调时间/预算。
- 回放精度不是 0.5° 验收：JTC 目标容差用驱动既有 4° 跟随门限，跟踪误差与终点误差单独记录、显示；动作成功 ≠ 精度通过。

## 4. 身份与版本

- 记录头写驱动实际运行的 boot_id、mapping/URDF/policy/重力档案四个哈希、policy_profile、load_id、Kp/Kd/α/斜坡、reference_speed、当时 URDF 限位。
- 加载历史记录允许不同 boot_id（重新连接/重启驱动），但要求当前运行身份的四个哈希与 load_id 与记录一致；不一致（改 URDF/映射/策略/重力档案/负载）拒绝预览，需要显式重新采集，不做静默重映射。
- 记录内部禁止混合：同一记录要求单一 boot_id、单一 command_id、单一身份指纹，否则判不完整。

## 5. 接口与界面

- 后端新增：`start_teaching_record / stop_teaching_record / save_teaching / list_teachings / load_teaching / preview_teaching / execute_teaching`；HTTP：`POST /api/teaching/record/start|stop`、`POST /api/teaching/save|preview|execute`、`GET /api/teachings`、`GET /api/teachings/<id>`；`GET /api/plans` 与 `GET /api/plans/<id>` 同时返回已保存教学（`kind: teaching`），保存后的示教出现在现有载入列表。
- 网页新增“拖动示教”卡片：开始记录 / 停止记录 / 记录阶段（渐入、有效记录、结束失能）/ 帧数、时长、间隙、boot/命令 ID、完整性 / 命名保存 / 载入 / 速度比例（默认 0.5）/ 预览（接近段、原时长、重定时总时长、关节范围、峰值速度、误差界、警告）/ 执行回放（每次重新确认三项确认 + 拖动示教确认）。
- 预览票根、单次使用、姿态漂移 0.5°、心跳租约、会话预算、停止纪元门禁全部沿用既有实现。

## 6. 本轮验证

- 离线（`test_drag_teaching.py`）：schema/独占创建/内容哈希/名称与路径分离/篡改/缺轴/NaN/时间倒退/陈旧帧/重复帧/混 boot_id 与 command_id/越限/超速/预算/接近段/误差界/速度比例边界。
- 真实 ROS/JTC + PTY + 真实 PanelBackend/HTTP（`verify_drag_teaching_e2e.py`）：自由拖动记录（模拟夹具拖动）→ 停止 → 保存 → 载入列表 → 预览 → 回放（仅模拟夹具），并验证回放报文为正常位置控制（Kp=160，非零刚度）、停止门禁/心跳丢失/停止竞态/保存失败仍完成停止/UNKNOWN 与陈旧反馈拒绝。
- 浏览器（`browser_drag_teaching.py`）：真实页面记录阶段、载入列表、预览显示；不执行实机动作。

## 6.1 复验返工（2026-11-06，Codex 5 项）

- **运行身份绑定票根**：预览时把驱动实际运行身份（`normalize_identity` + `identity_fingerprint`）写入冻结回放规格与票根；执行入口先核对当前 `/slaihand/runtime_identity` 与票根 fingerprint，不一致返回 `IDENTITY_CHANGED`，不进入启动入口。客户端在 arm/使能前再次订阅并核对冻结身份，不一致则拒绝使能并如实记录原因。
- **源时间戳去重**：动态帧记录保留发布者 `header.stamp`，样本时间优先使用原始时间戳，按源时间戳去重；重复投递只计 duplicate、不产生新样本。源时间戳或接收单调时钟倒退立即关闭窗口并标记不完整。
- **正常结束判定收紧**：只有 stage 7/8 且反馈有效、反馈年龄/数值/限位/驱动身份/command_id 全部健康才算正常停止；UNKNOWN(9)、反馈无效、年龄超限等故障帧一律判不完整。
- **无帧诊断记录**：渐入期间停止、尚无有效帧/身份时仍落盘严格 schema 的不完整记录并在页面显示摘要；命名保存为可回放示教仍要求 `complete=true`。

## 7. 明确限制（后续）

- 首版沿用 5 秒自由拖动窗口，更长拖动会话、记录中暂停/续录、多段拼接、曲线简化与力位混合回放列入后续。
- G07/质量档案、α 修改与参数应用不在本轮；实机部署由 Codex 验收后另行人工执行。
