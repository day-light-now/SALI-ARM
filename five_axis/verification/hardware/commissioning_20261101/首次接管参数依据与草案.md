# 四轴首次接管：参数依据与草案

日期：2026-11-01。软件零位和正方向采用当天人工标定；MuJoCo含J3固定摆放180°修正。

结论：电机规格、历史试动条件与本轮诊断结果已整理；可提出有机械支撑的低输出短时接管候选，**尚不能把这些候选称为四轴MIT安全包络或批准联动**。本轮只修改本地文档/草案，不连接串口、不写电机参数、不使能。

J1/J2的1.4961A来自模式4字段150/10000乘J10010L手册的标幺基准99.74A（手册第6–7页）。99.74A是该模式的标幺分母，与目录峰值相电流95A不是同一个参数定义，不能互相替换。

J1历史曾读到KT_Value=0，不能据此推定电机损坏，也不能据此建立准确的Nm→A换算。额定扭矩÷额定相电流不等于已校准的FOC Iq/输出扭矩常数；相电流RMS/峰值、齿轮效率、固件定义均需核对。本轮不将0.5Nm或0.3Nm换算为安培，不修改KT、OC或任何电流环参数。

## 3. 有支撑的候选参数，不自动加载或执行

这些数值是低输出调试的工程起点，**不是厂商推荐值、不是现成验收限额，也不保证能够托住整臂**。选择它们是为了从低输出开始观察受限接管；“低于额定值”本身不证明人员、夹具或机械安全。

|---|---:|---:|---:|---:|
| 主机总请求力矩候选上限 N·m | 0.50 | 0.50 | 0.30 | 0.30 |
| 12位编码后实际请求最大幅值 N·m | 0.43956 | 0.43956 | 0.27692 | 0.27692 |
| 主机Kp（N·m/rad）候选 | 4 | 4 | 4 | 4 |
| 主机Kd（N·m·s/rad）候选 | 0.5 | 0.5 | 0.5 | 0.5 |
| 驱动MIT kp/kd | 0 / 0 | 0 / 0 | 0 / 0 | 0 / 0 |
| 相对接管起点的中止位移界限 | ±2° | ±2° | ±2° | ±2° |
| 后续微动目标候选 | 1° / 2秒 | 1° / 2秒 | 1° / 2秒 | 1° / 2秒 |
| 指令速度候选上限 | 0.02rad/s | 0.02rad/s | 0.02rad/s | 0.02rad/s |

首次动作只请求保持**刚读取的当前位置**，不回软件零位、不调用旧J3回参考工具、不使用以前快照中的位置。输出斜坡1秒，整个首次候选保持试验限时2秒，结束尝试失能并等新反馈确认。手动停止或任一轴异常撤销整个计划；USB断连不能保证FD送达，依靠已落实的被动支撑和现场切电。

主机使用 `tau = Kp*(q_target-q) + Kd*(v_target-v)` 后限制总请求力矩并校验编码后幅值；驱动增益为0，所以不另叠加隐藏的驱动PD输出。编码零扭矩不是严格0，J1/J2半个力矩量化步长约0.04884Nm，J3/J4约0.01319Nm。限幅值控制的是协议请求，不是经过校准测力证明的实际输出，也不是独立硬件电流限制。

先不向实机添加模型重力前馈。若支撑改变、轴漂移、输出不足、跟随超差或不动，停止并分析，不自动增加力矩、增益、持续时间或运动角度。

1°/2秒最小跃度轨迹的理论最大参考速度约0.01636rad/s，小于0.02rad/s；这只是参考轨迹校验，不证明实机速度、跟随误差或碰撞安全。±20°仍是将来目标范围，未冻结为安全许可。J1完整限位仍在加工。

## 4. 为什么候选首先看J4

J4有当天新固件/参数会话的近零输出D状态观测，位于末端侧，当前暂估模型中重力矩较小。把这些作为优先验证顺序依据，比固定挑J3更清楚；不据此称其他轴不能运动，也不把J4测试结果推广到四轴。

按13:18试验起点和当前MuJoCo暂估惯量计算，四轴重力矩约 `[0.378,-0.105,0.00085,0.0418]` Nm，仅用于判断调试顺序和数量级，**不写成真实前馈或输出限额依据**。源模型明确 `ESTIMATE_ONLY_NOT_FOR_HARDWARE`，CAD质量/质心、末端负载和安装状态仍须核对。详细输入保存于 `gravity_pose_estimate.json`。

## 5. 准入缺项与接下来怎么做

1. 当前四轴配置必须由同一独占串口的新会话回读，而不是读取界面缓存。模式1、TIMEOUT2000、状态0、软件零偏摘要及角度分支一致；跨360°时不自动模运算或回零。
2. 当前位置附近的支撑、线束和至少±2°空间需按实际装配确认；本轮只提出候选界限，没有测量碰撞余量。
3. 验证候选非零输出和保持行为前，实际驱动保护退出行为仍需明确；D状态、无明显运动、清故障回0，各自只是证据的一部分。不能因记录中有“D”就把 `physical_torque_off_verified` 改成true。
4. 每轴真实运动和停止验收仍独立进行，不能将mode4电流限额自动转为MIT许可，也不能把J4报告写作J1–J3全部通过。
5. 增益和输出上限的有效性须由短时、有支撑、可立即切电的受控试验验证。草案不授予任何使能权限，真实桌面网关保持关闭。
6. 如要求**独立硬件限流的安培级保证**，先取得当前固件的电流口径/Imax/扭矩常数及保护设置含义，再决定是否使用专门的mode4限流通道或受控电流参数；不要把修改TMAX当成实际限流。

下个软件交付应是单一、限时的“J4当前位置接管”实验页面，清楚展示候选输出、时长、现场支撑条件和结果；不通过取消整臂网关R2来暴露全部控制。该页面在候选参数与试验条件明确前不发送使能。
