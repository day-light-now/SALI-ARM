## 质量和坐标约定

- 用户确认安装方向没有变化，继续使用原约定：基座重力 `[0, +9.80665, 0] m/s²`，J3 固定放置偏置 `π`。
- 用户明确：**新增3.5 kg不含 J5 电机本体，电机固定在 J4 连杆上**。
- 既有质量审计的 link4 已包含 J4340 电机，采用供应商总质量0.362 kg；本次不重复增加该电机。旧模型仍有自身辨识/质量误差，并未因沿用而视为绝对真值。
- 新增盒体建模为固定在 link4 上的刚体负载，不增加 J5 重力自由度，不使用虚构的 J5 安装原点。
- 输出质心是 **canonical URDF 的 link4 局部坐标**，原点就是 CAD 定义的 J4/link4 原点，单位米或毫米。不是相对电机壳中心、不是基座坐标，也不是现场可目测直接代入的左右上下距离。
- `effort` 已在驱动中乘 hardware_sign，是模型坐标力矩估算；审计 request_estimate 是电机坐标，J4 需乘−1后比较。本次已统一，未将两者直接混用。

## 数据处理

四份压缩原始文件与 manifest 中 SHA-256 全部一致，artifact/evidence 哈希亦一致；各 plan 与 client 中 plan 内容一致。补充从 client 所指本地日志中提取 SESSION 与 CONTROL_CYCLE，保存哈希及压缩副本，因此此目录可独立离线复现，不依赖之后是否保留 WSL 日志。

| Session | 有效窗口 | 处理 |
|---|---:|---|
| A | 9 | 剔除 A_9：client无采样；不把停止后的数据用作静态力矩 |
| A2 | 6 | 相对起点返回，不当作绝对零点 |
| B2 | 7 | 相对起点返回，不当作绝对零点 |
| C | 8 | 最后目标为绝对五轴零位；计算使用实际反馈姿态 |
| 总计 | 30 | 每个窗口是一份辨识观察，不把100Hz采样数当作独立姿态数 |

以**完整目标值匹配与参考速度为零**确定真实 plateau，按计划 arrival/end 对齐时钟，取 dwell 内末尾2秒，避开末端0.15秒边界。控制器/审计目标到达对齐的跨窗口偏差均小于0.6 ms。

再与最近 dynamic/audit 记录对齐，要求：使能反馈有效、命令身份一致、HOLD/TRACK、audit正常、反馈年龄≤60ms、TIMEOUT2000、无配置冲突、各轴速度绝对值≤0.035rad/s、已写增益当前且写入年龄≤50ms、窗口内各轴位置跨度≤0.4°。排除10条A中的非有限/不完整controller记录。每窗口保留实际平均姿态、波动、位置跨度、有符号误差、effort均值/中位数/标准差及实际编码Kp。

## 拟合方法

解析 canonical 四轴 URDF，使用 `T_parent × T_origin × R_axis(q+offset)`；joint origin 的平移按父坐标系解释，不被 rpy 再旋转。

重力保持力矩为 `τ = ∂U/∂q`。对质量与一阶质量矩建立物理线性回归器：

```text
τ(q) = Y(q) θ_old + 3.5 Y_link4,mass(q) + H_link4(q) h_box
h_box = 3.5 * c_box
```

`θ_old` 使用原四轴重力辨识模型表达的重力函数，仅作为固定先验；质量审计模型另外用于敏感性对照。没有把旧 `no_end_load` 文件直接当成当前负载档案部署。

先用 A/A2/B2 的22个窗口拟合，C的8个窗口单独评估。所有30点重拟合是后续单独列出的候选，不能用它重新声称C独立验证通过。

| 参数 | 22点训练模型 | 全30点重拟合候选 |
|---|---:|---:|
| x / mm | 96.3 | **109.6** |
| y / mm | 6.6 | **9.2** |
| z / mm | −42.0 | **−47.5** |
| hx / kg·m | 0.336941 | 0.383560 |
| hy / kg·m | 0.023113 | 0.032352 |
| hz / kg·m | −0.147050 | −0.166144 |

按整个静态窗口重采样2000次，全数据条件候选的2.5–97.5百分位区间：x `[84,138]` mm、y `[3,17]` mm、z `[−63,−32]` mm。**这仅是固定原模型、固定3.5 kg假设下的采样变化，不是实物质心的95%置信区间。** 不含静摩擦、原模型误差、质量误差及力矩标定误差。

## 为什么仍不能确定真实三维质心

**第一，z与原连杆参数存在结构耦合。** 假定原重力函数完全固定时，新增负载的3个一阶矩回归器满秩；若同时允许原连杆参数变化，16列静态重力回归器秩为8。link4 的横向 hx/hy 在理想模型中可辨识，轴向 hz 不能单独与上游一阶矩分离。

程序保存了一个明确反例：各连杆质量全部不变，把 link4 hz 增加0.35kg·m，同时按 J4 固定旋转将 link3 一阶矩作相反调整，任意姿态重力矩不变到浮点误差范围。这等价于3.5kg盒体质心z改变100mm而力矩不变。因此，若原连杆一阶矩本身不确定，**单纯继续增加同类静态姿态不能唯一解决z**；必须增加独立几何/质心约束或可靠的装载前后差分。

**第二，记录力矩有明显路径依赖。** 例如：

| 近重复窗口 | 最大关节姿态差 / ° | 明显力矩估算差 |
|---|---:|---|
| A_0 → A_8 | 0.546 | J1约−1.54Nm |
| A2_0 → A2_5 | 0.504 | J1约+1.66Nm |
| B2_0 → B2_6 | 0.562 | J1/J2约+1.64Nm |
| B2_3 → C_5 | 0.590 | J3约−1.62Nm |

近姿态不等于完全相同姿态，但这些差异足以提醒：不能把每个静态effort全部当成纯重力。静摩擦、传动回差/弹性、支持状态变化及估算偏差均可能贡献；本次数据不能唯一确定原因。

**第三，模型假设改变会影响质心。** 以全30点为例：

| 条件 | x / mm | y / mm | z / mm |
|---|---:|---:|---:|
| 固定旧辨识重力函数 | 109.6 | 9.2 | −47.5 |
| 固定旧CAD质量函数 | 107.5 | 6.6 | −38.5 |
| 固定旧辨识函数，再加每轴常值偏置 | 104.5 | 55.2 | +23.4 |
| 稳健soft-L1拟合 | 105.6 | 6.8 | −44.6 |
| 改用已对齐的主机PD请求代理 | 109.4 | 9.6 | −51.5 |
| 新增质量假设3.0kg | 141.8 | 10.6 | −50.7 |
| 新增质量假设4.0kg | 85.4 | 8.2 | −45.0 |

这说明应称为“条件有效质心候选”，不能把三位小数作为测量精度。3.5kg仍是估计而非称重；J5电机本体不包括在新增质量里。

## 已交付的补偿计算

- `offline_ff_candidate.json`：原重力函数加新增负载的线性系数、坐标约定、观测角度范围及来源哈希；明确 `deployable:false`，不采用生产负载profile schema。
- `evaluate_offline_ff.py`：离线计算四轴总保持力矩与新增盒体贡献，同时给出模型/电机坐标结果；拒绝非有限角度和超出记录角度包围盒的外推。包围盒本身不代表已验证的组合姿态覆盖。
- `static_windows.json/.csv`：30个窗口的计算输入与筛选证据。
- `identification_result.json`：系数、保留验证、敏感性、窗口重采样及不可辨识反例。
- `extract_audit.py` 和压缩cycle副本：补足原交接目录未包含的完整增益证据。

在工作树根目录运行：

最后一条仅打印离线结果。例如该姿态的总模型保持力矩约 `[2.77,3.34,−0.041,0.734] Nm`；这些数值不是可直接下发的上机指令或已验证允许输出。

## 对后续补偿的具体建议

当前数据已经处理完，无需重新跑一遍同样的30点。优先补充的是：**新增盒体实际称重，以及 link4/J4 原点到盒体质心轴向位置的独立几何约束**；这直接针对质量与z的不确定性。

若之后另行做现场识别，应该在相同绝对姿态、相同载荷下做正反接近配对，或同姿态装载前后差分，以分离摩擦/旧模型贡献；不能用一次回零或更多单方向点代替。需要先规划障碍/限位与保持方式，本次没有自动执行这些动作。真实每轴电流/扭矩标定有助于验证力矩尺度，但并不能单独消除静摩擦和轴向参数耦合。
