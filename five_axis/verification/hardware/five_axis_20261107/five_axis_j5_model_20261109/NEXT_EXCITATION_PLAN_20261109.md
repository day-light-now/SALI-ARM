# 下一轮激励草案：配对接近方向的静态辨识（未执行）

状态：**只是草案；不构成运动授权。** 不启动 driver、不写参数、不执行任何轨迹。
真实施行前必须：操作者在现场、机械臂有支撑/净空、可随时切电、STOP 可用；
admission 链完整（J5 TIMEOUT 读回 2000 → evidence → artifact）；4° 跟随误差、
限位、反馈新鲜度/admission、J5 watchdog 全部保持不放宽。

## 为什么需要这一轮

`README_J5激励数据复核_20261109.md` 的结论是：单方向静态窗口里的 `effort` 含
静摩擦/粘滑偏置（本次实测 J1 0.75 Nm、J4 0.86 Nm 的粘滑释放），而 J5 的
±20° 激励又不足以把“J5 输出负载重力项”与回差/线缆效应分开。既有 30 姿态数据
同样有 ~1.5 Nm 的近重复姿态不一致。**在消除/估计静摩擦之前，任何质心拟合都是
条件估计，不能部署。**

配对接近（同一姿态先从正方向、再从反方向靠近并静置）是最小代价的办法：

- 同一姿态两次静置的 sag 差 `Δq_pair` 主要来自静摩擦偏置（方向相反）；
- 两次平均 `q̄ = (q_up + q_down)/2` 把一阶静摩擦偏置抵消掉；
- `Kp·Δq_pair/2` 就是该姿态静摩擦偏置的估计，可直接作为后续模型拟合的
  数据权重/门限。

## 数据设计原则

1. 每个目标姿态都成对出现：一个从较小角度升上来（up），一个从较大角度降下来
   （down）；两段移动方向相反，之间不经过目标姿态以外的动作。
2. 每个窗口保持至少 6 s，取最后 2 s 做静态估计；移动 6–10 s，参考速度不高于
   既有候选（≤0.15 rad/s 等效），五轴同时使能、J1–J5 全部在限位内。
3. 每次会话最后一点必须是绝对 `[0,0,0,0,0]`；不允许以相对零代替。
4. J1–J4 不能全在零位：至少一半姿态要让 J1/J2/J3/J4 有独立激励，否则 30 姿态
   数据暴露的秩亏问题会重现。
5. J5 范围先 0/±10/±20°；若第一轮配对一致性好、且现场余量允许，再考虑 ±30/±45°。
   J5 绝对限位 ±90° 不变。
6. 全程不启用重力 FF（alpha=0），不改增益/限位/4°/STOP/看门狗。
7. 每条会话 ≤10–12 个路点，避免超时/会话上限；先编译校验再执行。

## 采到数据后怎么判定

1. 对每个配对：`Δq_pair = q(up) − q(down)`（各轴、度）；换算静摩擦偏置
   `b = Kp_encoded·Δq_pair/2`（Nm）。若 `b` 与 q5 无关而近似常数，说明是关节
   摩擦，不是 J5 重力。
2. 用配对平均的姿态/力矩重拟合载荷质心（沿用 `five_axis_model_j5.py` 的模型与
   先验），留出集必须单独保留（例如按会话留出）。
3. 只有当：(a) 留出 RMSE 显著低于静摩擦门限（目标 <0.15 Nm，接近旧四轴模型的
   0.158 Nm 量级）；(b) 随 J5 转动的质心项在配对平均后仍有一致、可重复的
   q5 依赖（大于 2×b 的不确定度）；(c) 固定 link4 与随 J5 转动两个假设能被
   数据区分——才进入“有界五轴 FF 设计”。否则 J5 重力项按 0 处理，不实现 FF。
4. 记录：每窗口 sag、effort、kp_encoded、audit request、配对差、静摩擦估计、
   拟合结果、留出指标。仍不声明 1.5×/热/稳定性/精度验收。
