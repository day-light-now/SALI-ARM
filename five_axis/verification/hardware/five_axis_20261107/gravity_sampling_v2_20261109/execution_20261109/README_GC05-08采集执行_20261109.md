controller_state + dynamic），再运行受保护客户端

--load-id j5_3p5kg_provisional --execute --ack-supported --ack-clearance

| GC08 | 0 | −0.852 | −0.142 | −0.284 / +0.328 |

要点：

1. J5 effort 的方向半差 **0.49–1.01 Nm**，与既有 6 点数据的 0.80 Nm 同量级，
   说明 0.5° 判据下的静摩擦主导仍然存在；直接单方向拟合会把摩擦学成重力。
2. 同一次运行的 up/down 实际 q5 相差 0.3–0.7°，即静摩擦把平衡位置推开；
   模型拟合必须使用**实际反馈 q5**，不能只用目标角。
3. 上游 J1–J4 的配对半差 ≤0.013 Nm（GC08 J4 最大），说明在这些基准姿态下
   J5 转动 40° 对上游转矩的方向依赖很小；上游绝对力矩随基准姿态变化
   （如 GC06 J2≈+6.20 Nm、GC07 J4≈+2.9 Nm、GC08 J1≈+4.15 Nm），可供模型
   约束 J1–J4 参数。
4. 配对均值（一阶摩擦抵消后）的 J5 力矩：GC05/GC06（J1–J4 近零或仅 J2=20°）
   在 ±10°/0° 都接近 0（−0.13…+0.03 Nm）；GC07/GC08（J3/J4=20° 或混合姿态）
   为 −0.06…−0.16 Nm。这个随基准姿态的 ~0.15 Nm 变化是下一步重拟合要验证的
   信号，但它仍低于方向半差 0.5–1.0 Nm 的摩擦量级，**不能直接据此认定 J5
   重力项**。

## 5. 明确边界

- 本轮是“采数据”，不是精度、热、1.5× 或 FF 验收；`effort` 仍是估计力矩。
- 0.5° 逐点判据未过是重力静差，不是安全故障；如果要求“逐点通过”，需要降低
  目标幅度或改判据，不能通过放宽 4° 安全门限来达成。
- 没有启用重力补偿；没有修改任何 driver/policy/load/URDF/质量声明。
- 结论仍以 `../README_新采集轨迹.md` 与 `../five_dof_identification_20261109/
  README_五轴模型修正.md` 的“未选定可部署参数”为准；GC05–GC08 只是为
  “分离摩擦与重力、验证 J5 轴/质心”提供新数据。
