# 更新的J5输出载荷采集轨迹：GC05–GC08

2026-11-09；新增3.5kg盒体随J5输出转动，电机本体仍在J4。

**新轨迹包含J5双向接近配对，并在不同J1–J4姿态下重复。每条都是绝对坐标，最后目标严格为 `[0,0,0,0,0]`，停留8秒。** 本目录只生成/校验与导入计划，不执行运动或开启FF。

| 上位机已保存计划前缀 | J1–J4采样基准姿态 / ° | 内容 | 时长 |
|---|---|---|---:|
| GC05 新采集 | `[0,0,0,0]` | J5双向配对 | 120秒 |
| GC06 新采集 | `[0,20,0,0]` | J2改变后，同一J5配对 | 146秒 |
| GC07 新采集 | `[0,0,20,20]` | J3/J4改变后，同一J5配对 | 146秒 |
| GC08 新采集 | `[10,10,10,10]` | 混合姿态，保留为独立验证 | 146秒 |

在各自基准姿态，J5序列为：

```text
0 → +10 → +20 → +10 → 0 → −10 → −20 → −10 → 0
```

这提供三组成对目标：+10°从0和+20°两边接近；−10°从0和−20°两边接近；0°从+10°和−10°两边接近。±20°用于转向，不把它们冒称为双向配对。

GC06–GC08先从五轴绝对0进入基准姿态，序列结束后再回到**所有轴绝对0**。GC05的基准姿态就是零，因此没有连续重复的相同零路点，以免采样时把两个不同计划窗口合并。

## 时间与检查

- 每段移动8秒，普通目标停留5秒，最终五轴零停留8秒。
- 每条9或11个路点，不超过现有12点限制；最长146秒，为180秒session保留34秒。
- 使用现有 `joint_waypoint_plan.compile_plan` 校验：canonical J1–J4限位、已记录J5 ±90°标定范围、五轴维度、绝对终点、速度及预算。
- 候选参考峰值≤0.15rad/s；J1–J4不使用负角目标，J5不超±20°。这是关节参考检查，未宣称碰撞/线缆净空已经验证。
- 候选入口要求五轴新鲜反馈在绝对零±2°内；实际起点更远应重新规划入口，不把之前回零结果当作当前姿态。
- 分别用全零和两个非零起点编译，最终目标都保持精确五轴绝对0。

## 上位机用法

刷新页面，在“已保存计划”里选择 **GC05～GC08 新采集**，点击载入。加载会切换到软件绝对角度、普通“轨迹跟随”，并保留绝对零终点检查。改成相对坐标或修改末点为非零时，界面拒绝提交。

这里用普通轨迹模式配合原始 `controller_state + dynamic` 录制；不是旧四轴“重力采样组”资格，也不会自动启用FF或拟合。每条单独session，不将四条拼成一条长session。

采集应保留完整plan、client、约100Hz原始状态、实际编码增益及写入状态、runtime identity、audit和SHA。记录名与GC05～GC08对应。按计划dwell取窗口，分别保留两种接近方向；满足状态/静止/反馈新鲜度后，才可计算配对均值和半差。GC08不要并入同一轮训练后再宣称独立验证。

TIMEOUT维持2000。当前已是2000时可用 `--verify-existing` 的真实只读新证据，零参数写入；不要求为了取证而断电或重写。实际读回0时仍需正确设置后重新取证；不关闭watchdog，不复用过期准入。

用户要求的“每条终点是0”落实为每条正常轨迹的最后参考点与8秒停留。实际回零还需最终反馈窗口通过；异常STOP/UNKNOWN时不强制继续运动回零。
