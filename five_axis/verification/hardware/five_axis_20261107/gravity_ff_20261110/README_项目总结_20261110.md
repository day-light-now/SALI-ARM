# 项目总结：SLAI 五轴机械臂静态重力补偿（2026-11-10）

## 1. 目标与硬件

- 目标：在五轴机械臂上实现可用的重力补偿，并为后续拖动示教/转矩前馈评估条件。
- 硬件：J1–J4 四轴 + J5（电机盒/3.5 kg 负载盒）；最新状态为**原电机盒装回**，
  工程配置使用 `load_3p5kg_provisional.yaml`（provisional load）。
- 软件：ROS 2 Jazzy（WSL Ubuntu 24.04）、USB-CAN、五轴候选准入链。

## 2. 已完成的能力

1. **位置前馈静态重力补偿（主交付）**：测量稳态下垂 → 修正指令 → 迭代；
   JZ 基线 RMS 0.632°/max 1.017° → 迭代 2 次 **RMS 0.0775°/max 0.164°**。
2. **模型补偿计划转换器**：由 `sag_model` 直接生成补偿计划，带训练域/幅值/限位/
   端点保护；域外计划（大角度混合姿态）会被拒绝。
3. **一键流程**：`run_compensation.cmd` 默认 **hybrid**（模型补偿 + 一次实测修正），
   保留旧 iter 三轮路径和离线 plan-only 模式；hybrid 的修正以**原始目标**为基准。
4. **测试套件**：H1 域内留出基线/补偿 A/B、H2 两侧重复性、H3 J5 正反、H4 三方向
   粘滑，共 6 条计划；dry-run、单元测试、合成数据全链路、hybrid 合成演练均通过。
5. **离线诊断**：无先验重力重拟合（CV 0.65 Nm）、摩擦实测、姿态设计、串口故障
   日志特征分析。

## 3. 关键数据（残差口径：实测 − 原始目标）

| 项目 | RMS | max |
|---|---:|---:|
| V1 未补偿基线下垂 | 0.484° | 1.531° |
| 模型预测下垂误差（V1，11 点） | 0.230° | 0.525° |
| V1subc 模型补偿后残差（8 点） | **0.205°** | 0.443° |
| 逐点迭代补偿（JZ iter2） | **0.0775°** | 0.164° |
| hybrid 合成演练（模型→一次修正） | 0.080° → 0.0074° | 逻辑验证，非真机 |

摩擦实测（滑动）：J1 1.09、J2 0.98、J3 0.55、J4 0.92、J5 0.94 Nm。
J5 耦合：电机盒质心近 J5 轴，J5 重力项 <~0.1 Nm；J5 摩擦主导。
静态重力模型可辨识性：16 参数仅 8 维可辨识，条件数 ~23；无先验 CV 0.65 Nm；
再采同类静态数据收益 ~0（0.661→0.657 Nm），加摩擦项无改善。

## 4. 尚未开放的能力与原因

- **转矩前馈 / 自由拖拽 / 零力示教：未开放**。
  - 当前 `effort` 是 PD 重建估计，无独立力矩/电流传感器、无已知力矩参考；
  - 机构摩擦 0.55–1.09 Nm，静态模型下限约 0.65 Nm，达不到安全浮动精度；
  - provisional load 准入禁止 `gravity_ff_alpha>0` 与 `gravity_float_enabled`。
- 解锁条件（至少其一/组合）：① 力矩/力参考与 effort 绝对标定；② 机械减摩
  （电机盒/关节改造）；③ 准入策略升级并有独立验证。没有新证据前不放宽。

## 5. 安全不变量（未改动）

4° 跟随误差硬保护、STOP/UNKNOWN、URDF 限位、反馈新鲜度/会话准入、
J5 watchdog 2000；FF alpha=0；GC13 冻结；每轮计划首末绝对零。

## 6. 串口故障特征（离线日志分析）

扫描到 69 条相关日志：`serial_write_fault` 33、`WRITE_SUPERVISION_FAILURE` 19、
`process_died` 6；日期分布 11-05/06/07/09/10，11-10 最多（28 条）。
表现为 `CANUSB incomplete serial packet write` → 驱动 DISABLED → 客户端停止。
处置原则：立即停止 → 确认支撑/失能 → 面板复位 → 最多重试一次，不连续重试；
优先软件复位、避免快速重启驱动。

## 7. 下一次真机计划（约 10–15 分钟）

1. 挂 USB、五轴准入（TIMEOUT 只读回验 → artifact → 候选驱动）；
2. `bash run_test_suite.sh --run --stop-driver`：H1 A/B、H2、H3、H4；
3. 自动汇总 H1 基线/补偿、H2/H4 重复性与阈值；
4. 再跑一次 `run_compensation.cmd` 验证 hybrid 默认路径（选域内计划）；
5. 通过后把结果补进报告并同步仓库。

## 9. 结论

**位置前馈静态重力补偿已达到可交付水平**（迭代 0.08°、模型一次补偿约 0.2°），
并有可复用的转换器、一键流程、测试套件和完整离线验证。转矩 FF/自由拖拽仍被
测量链与摩擦限制锁死，需要外部条件才能推进；当前不对外承诺这两项能力。
