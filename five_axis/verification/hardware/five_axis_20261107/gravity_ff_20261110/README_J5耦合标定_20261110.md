# J5 输出耦合实验（2026-11-10）

目的：在"3.5 kg 盒确实装在 J5 输出法兰上"的前提下，判断 J5 转动是否产生可测的
上游重力信号，从而决定是否值得做 J5 轴线/质心标定与 effort 绝对标定。

## 方法

- 自动计划 `plans/J5COUP_20261110.json`：两个倾斜基准姿态，J5 在 0/−30/0/+30/0
  双向扫动，12 路点，6 s 移动 + 6 s 停留，首末绝对零。
  - 基准 A：`[0,20,15,10]`（J5 轴不平行重力的姿态）
  - 基准 B：`[15,25,-15,-10]`
- 每路点取 dwell 最后 2 s 的反馈位置与动态 `effort`（effort 是 PD 位置误差重建的
  力矩估计；此处只用窗口间差分，不做绝对标定）。
- 对每个基准姿态拟合 `effort_j(q5)=A·sin(q5)+B·cos(q5)+C`；若盒随 J5 转且质心
  偏轴，上游 J2/J4 应出现与 q5 平滑相关的正弦项。

## 判定

- **J2 是重力最敏感的轴**：在 q5 扫 ±30° 时变化仅 0.0055（A）/0.0153（B）Nm，
  远小于力矩码 0.098 Nm。若盒质心横向偏轴，按 0.0235 Nm/mm 灵敏度，这里对应
  横向偏移 ≲1–2 mm 的上界。
- **J1/J3 在基准 B 的"振幅"不是重力**：J1 effort 序列
  `4.249,4.249,4.247,3.808,3.810`、J3 `-1.543,-1.194,-1.198,-1.204,-1.200`，
  是 q5 正/负向移动后的**离散粘滑台阶**（一次性跳变后保持），不是随 q5 平滑变化
  的正弦；与历史 J1/J4 粘滑释放（0.75/0.86 Nm）同量级。
- **J5 effort 的大"振幅"是摩擦**：J5 的 ±q5 方向对应 effort 约 ±1 Nm，
  方向相关、非正弦，和 2026-11-09 独立复核的 0.8–0.9 Nm 粘滞一致。

## 结论与决策

1. **J5 输出负载的重力项可忽略**（≤0.1 Nm 量级）；3.5 kg 盒的质心几乎在 J5
   轴线上。因此**不需要**做 J5 轴线/轴心标定来改善重力 FF；之前的"J5 转动上游
   无响应"矛盾解释为质心近轴，而不是固定载荷。
2. J5 仍是**摩擦主导**关节（0.8–1 Nm 粘滞/回差）；自由拖拽/零力示教需要摩擦
   补偿，而不是 J5 重力项。
3. **effort 绝对标定仍是转矩 FF/自由拖拽的硬前提**：effort 是 PD 重建估计，
   绝对值有偏置；没有已知力矩参考（已知质量/力臂或力计）就不能给 FF 认证。
   当前现场没有称/已知重物，所以今天到此为止，FF alpha 保持 0。
4. 若之后更换电机盒/负载：需重做本耦合实验（质心可能变化），但 J5 轴本身是
   关节属性，不受盒体更换影响。
