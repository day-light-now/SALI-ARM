# Offline simulation artifacts (synthetic, not hardware data)

Everything under this directory is generated by offline simulations:

- `simulate_suite.py` → synthetic windows for H1/H2/H3/H4 + analysis results;
- `simulate_hybrid_pipeline.py` → synthetic model/iter1 runs + hybrid report.

None of these files is a real measurement. Real hardware runs write
`windows_<tag>.json` and `runs/<tag>/` in the parent directory; the simulation
moves its outputs here so they never mix with hardware evidence.
