# 摩擦辨识与"摩擦修正后重力重拟合"（2026-11-10）

## 1. 采集

5 个单轴双向慢扫计划（F1–F5，每关节一组，±15–20°，~123 s，首末绝对零），
自动连续执行完成；tag `F1fr…F5fr`。其中 F3/F5 客户端判据通过（exit 0），
F1/F2/F4 仅因 0.5°/路点判据未过（与重力静差同性质，非安全故障）。
结束：驱动停止、串口释放、五轴失能；4°/STOP/限位/准入/watchdog 2000 未改。

## 2. 摩擦估计（同角度上行/下行 effort 半差）

方法：同一关节角度 q 处 `f = (effort(+v) − effort(−v))/2`，重力自动抵消；
按 0.25° 分箱，速度约 0.03–0.04 rad/s 的慢扫段。

| 轴 | 平均摩擦 | std | 范围 | q 覆盖 |

| J1 | 1.090 Nm | 0.198 | 0.718–1.532 | −13.0…+13.2° |
| J2 | 0.975 Nm | 0.103 | 0.700–1.254 | −3.7…+13.6° |
| J3 | 0.551 Nm | 0.055 | 0.442–0.744 | −14.5…+14.4° |
| J4 | 0.924 Nm | 0.102 | 0.419–1.193 | −8.8…+9.4° |
| J5 | 0.936 Nm | 0.124 | 0.468–1.206 | −19.4…+19.5° |

比之前从粘滑台阶估计的 0.75–0.86 Nm 更大；J1/J2 超过 1 Nm，J3 也有 0.55 Nm。
这解释了静态重力模型 ~0.65 Nm 的残差下限，也说明自由拖拽所需的手感会受很大影响。

## 3. 把摩擦项加进重力重拟合——没有改善

在"无先验 16 参数重力 + 常数 + 方向 + 会话"模型上，加入每轴 `f_j(q_j)*sign_j`
列（系数自由拟合，1.0 表示实测摩擦直接可用）：

- CV 总体：**0.6562 → 0.6587 Nm（无改善）**；
- 拟合出的摩擦尺度：J1 0.58、J2 0.80、J3 −0.04、J4 −1.28、J5 0.12
  ——符号/幅度不一致，说明"慢扫滑动摩擦"不能迁移到"静态保持粘滑"状态；
- 静态窗口的 effort 还含 PD 重建偏置（每轴 0.07–0.17 Nm），也限制了精度。

## 4. 结论（重要）

1. 在**当前测量链**（effort=PD 重建估计、无独立力矩/电流、无外力参考）与
   **当前机构**（0.55–1.1 Nm 摩擦/粘滑）下，静态重力模型的误差下限约
   **0.65 Nm**；继续采同类静态数据、或简单加摩擦项，都不能逼近 FF 所需的
   0.1–0.2 Nm。
2. 因此**转矩 FF 与自由拖拽/零力示教仍不能开**；不是"数据还不够"，而是
   测量分辨率和摩擦物理的限制。
3. 要往下走只有三条路（需要外部条件）：
   - 机械减摩（你计划中的电机盒/结构改动）后重测；
   - 引入已知力矩参考/力传感器/力计做 effort 绝对标定，并改善力矩反馈质量；
   - 更完整的动态辨识（多速度、多加速度、摩擦状态观测器），但仍受测量精度限制。
4. 已完成的**位置前馈静态补偿**（RMS 0.55→0.078°）仍是当前可交付的实用能力；
   它不需要转矩 FF，也不能支撑自由拖拽。
