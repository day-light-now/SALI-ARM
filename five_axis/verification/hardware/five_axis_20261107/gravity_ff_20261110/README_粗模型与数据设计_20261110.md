# 粗模型与下一轮数据设计（2026-11-10 离线）

## 1. 无旧先验的刚体重力重拟合

数据：159 个已接受静态窗口（`refit_gc09_12_20261109/static_windows.json`）。
模型：16 参数刚体重力（4 连杆 × 质量 + 一阶矩，无旧四轴先验）+ 每轴常数 +
方向摩擦项 + 每驱动会话偏置；J5 重力项=0（2026-11-10 耦合实验：盒质心近轴）。
验证：留一"命名会话"交叉验证（同一驱动会话内的不同姿态也留出）。

| 拟合 | 训练总体 RMSE | CV 逐轴 RMSE (J1..J5) | CV 总体 |
|---|---:|---|---:|
| OLS | 0.542 Nm | [0.711, 0.510, 0.330, 0.965, 0.122] | 0.646 Nm |
| Huber/IRLS 鲁棒 | 0.574 Nm | [0.708, 0.461, 0.266, 1.041, 0.123] | 0.656 Nm |

- 鲁棒拟合没有改善：离群粘滑不是主要误差来源。
- 可辨识性：16 参数中只有 **8 个方向可辨识**（Y16 秩 8，有效条件数 ≈23.1）。
- 结论：粗模型误差约 **0.65 Nm**（比旧候选 ~1.3 Nm 好一倍），但离转矩 FF/
  自由拖拽需要的 ~0.1–0.2 Nm 仍差 3–6 倍。

## 2. 下一轮姿态设计（D-optimal）

用现有信息矩阵在 8 维可辨识子空间里贪心选择新姿态（每姿态正反各一次），
候选网格 J1∈±20、J2∈{-5,0,10,20,30}、J3∈±20、J4∈±20（J5=0）：

- 选出 10 个训练姿态 + 8 个验证姿态；
- **预测验证 RMSE 仅从 0.661 → 0.657 Nm（-0.6%）**；
- 说明现有 636 行数据已经把 8 维重力子空间覆盖得差不多；**再采同类静态
  数据几乎没有增益**，瓶颈不在"数据条数"。

生成（未执行，低优先级）：`plans/T2_sag_20261110.json`（12 路点）、
`plans/T2r_sag_20261110.json`（反序）、`plans/V2_sag_20261110.json`（10 路点）。

## 3. 真正该做的下一步：摩擦/粘滑辨识

0.65 Nm 的残余主要来自静摩擦/粘滑与 effort 测量偏置，而不是重力参数。
静态窗口只能给出"方向项"这一阶；要压下去必须做**动态摩擦辨识**：

- 固定 J1–J4 中三个轴，让单轴以多个恒定速度（如 0.2/0.5/1.0 °/s）双向慢扫，
  每个速度段停留采样；
- 用 `reference_velocities` 与 effort 拟合每轴库仑+粘滞摩擦（必要时 stiction
  状态），把摩擦偏置从静态窗口里减掉后重拟合重力；
- 这一步同样可以自动采集（≤12 路点/计划，6 s 移动再放慢），不需要称重；
- 它也是自由拖拽的必需品（低 kp 浮动时摩擦必须补偿）。
