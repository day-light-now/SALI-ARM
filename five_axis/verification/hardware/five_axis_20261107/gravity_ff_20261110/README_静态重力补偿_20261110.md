# 2026-11-10 静态重力补偿（重力下沉前馈）实验结果

状态：**已完成。** 在没有 CAD、且 candidate 准入明确禁止 provisional load 开启
转矩前馈（`gravity_ff_alpha` 必须为 0）的前提下，今天实现并验证的是**静态位置
前馈型重力补偿**：用自动采集的静态窗口拟合每关节重力下沉模型，在目标位置上
叠加补偿偏移后执行，使实际稳态姿态回到期望姿态。**所有安全门限未改，FF alpha
仍为 0，GC13 未采。** 收尾时驱动已停止、串口释放、五轴失能。

## 1. 为什么不是转矩 FF

- `j5_motion_artifact.py` 的 candidate 准入硬性要求 provisional load 的
  `gravity_ff_alpha == 0`、`gravity_float_enabled == false`
  （`POLICY_FF_ALPHA_NONZERO` / `POLICY_FLOAT_ENABLED` / `LOAD_FF_ALPHA_NONZERO`），
  `slaihand_canusb_five_axis_candidate.launch.py` 也拒绝 provisional load 的
  gravity feedforward。这是安全门，不能绕。
- 因此今天做的是"位置前馈的重力补偿"：等价于在指令层预测并抵消重力引起的稳态
  位置误差（static sag），不改变控制器增益/力矩。**它不是转矩 FF**，不降低关节
  力矩，只消除稳态姿态误差；真正的转矩 FF 仍需锁定几何/负载模型并单独评审准入。

## 2. 执行链路（全部自动采集，无人工摆位）

1. USB 适配器重新 attach（usbipd `2-2 2e88:4603 COM9`），`/dev/ttyACM0` 恢复。
2. 隔夜断电导致 J5 TIMEOUT 回 0：按协议**写一次** 0→2000（`complete`，
   1 次尝试/1 次参数写入，回读一致），证据 `evidence/j5_timeout_write_once_20261110.json`；
   重建 truthful artifact（sha `a73d39cf…`，`timeout` 块如实记录）。
3. candidate 驱动启动，准入 `J5_QUALIFIED`；面板显示 DISARMED、五轴新鲜、
   J5 合格、TIMEOUT 2000。安全链不变：4° 跟随误差、STOP/UNKNOWN、限位、
   反馈新鲜度/准入、J5 watchdog 2000、FF alpha 0。
4. 自动采集（客户端硬限制：单计划 1–12 路点、总时间预算 178 s）：
   - T1a：12 路点，6 s 移动 + 6 s 停留，首末绝对零；
   - T1b：12 路点，同上；
   - V1：11 路点，留出混合姿态，同上。
   轨迹均完整执行（客户端 exit 1 仅因 0.5°/路点判据在重力下沉下不满足，
   与 GC01–GC12 同性质，不是安全故障）；raw 100 Hz + 客户端 JSON 已归档。
5. 拟合（T1a+T1b 共 20 个有效静态窗口，`samples≥150`）：每关节对
   `[1, q1..q5, q2², q3², q4², q1q2, q3q4]` 做岭回归（λ=0.02），
   训练 RMSE（deg）：J1 0.135、J2 0.224、J3 0.039、J4 0.126、J5 0.193。
6. 生成补偿计划：命令 = 期望 − 预测下沉（首末仍保持绝对零），在 V1 的 8 个
   未参与训练的混合姿态上验证。
7. 第一次补偿运行 V1c 被已知 USB 写故障
   `SERIAL_OR_AUDIT_WRITE_FAILURE` 安全中止（驱动停、客户端确认新失能，
   无危险动作，非补偿导致），随后改用较短的 8 姿态补偿计划 V1subc，
   **完整执行（trajectory_error_code=0，10/10 窗口）**。

## 3. 结果（未参与训练的 8 个混合姿态）

| 指标 | 补偿关闭 | 补偿开启 | 改善 |
|---|---:|---:|---:|
| 总体 RMS（deg） | 0.550 | **0.205** | 63% |
| 总体最大（deg） | 1.531 | **0.443** | 71% |
| J1 最大 | 1.307 | 0.385 | 71% |
| J2 最大 | 1.531 | 0.372 | 76% |
| J3 最大 | 0.235 | 0.096 | 59% |
| J4 最大 | 0.672 | 0.213 | 68% |
| J5 最大 | 0.306 | 0.443 | **−45%（变差）** |

- 典型姿态（J2=20°）残余从约 1.53° 降到 0.37°；J1/J2/J4 的补偿有效。
- J5 不升反降：J5 的静态误差在两次会话/不同接近历史下符号会翻转
  （实测零位约 ±0.3°，训练内也见 -0.28°→+0.17°），说明 J5 输出侧存在
  回差/摩擦或未建模的载荷自由度，今天的模型无法补偿它；需要单独采集
  J5 专项数据后再处理。
- 数据也显示同会话不同接近历史会带来约 0.3–0.5° 的滞回，因此残余
  0.2–0.44° 已是这套"位置前馈"在 ±20° 局部姿态域内的合理水平。

## 5. 限制与下一步

- 本结果是**稳态位置补偿**，仅在采集覆盖的局部姿态域（|q|≤20° 左右）有效；
  不是转矩前馈，动态过程不受益。
- 真 FF 的前置条件不变：J5 真实轴线/轴心/零位、effort 标定、负载质量/质心、
  模型 SHA/误差预算锁定，以及 candidate 准入从 provisional 升级；这些完成前
  `gravity_ff_alpha` 必须保持 0。
- J5 需要专项静态数据（固定 J2/J3/J4 多 J5 角度、双向接近）以区分回差与重力。
- USB 写长尾仍会随机打断采集（今天 V1c 即一例）；继续按既有策略：短会话、
  唯一日志、无缓冲、core 收集、故障安全停/确认失能、保留切电。

## 6. J5 专项补充（同日完成）

- 数据：固定基准姿态、双向 J5 扫描（J5A 基准 J2=15°；J5B 基准 J3=15°/J4=10°），
  各 12 路点；验证 JV 用未见基准 [8,10,8,5]，J5 在 -25..20° 内两次换向。
- 发现：J5 静态误差 **主要是回差/摩擦（约 0.28–0.38°），符号随运动方向翻转**，
  不是重力矩项；同一 q5 不同接近方向符号相反（如 q5=0：上接近 -0.31°，下接近
  +0.31°）。因此 J5 的补偿必须是方向感知的。
- 拟合：12 个窗口、特征 [1, 运动方向, q2,q3,q4,q5, 方向×q5]，岭回归；
  训练 RMSE 0.102°、最大 0.25°。
- 验证（JV 的 9 个有效路点，未见姿态）：稳态残余对比：
  - 总体 RMS 0.689° → **0.171°**；最大 1.028° → **0.361°**；
  - 逐关节最大残余：J1 1.028→0.284（-72%）、J2 0.951→0.361（-62%）、
    J4 0.519→0.213（-59%）、**J5 0.382→0.266（-30%）**、
    J3 0.238→0.283（略变差 -19%，模型在 J3 上仍有小偏置）。
- 局限：J5 补偿依赖计划中的运动方向（生成补偿计划时需知道上一目标），
  仍是位置前馈而非转矩 FF；残余主要来自回差幅度的姿态/方向差异。
- 运行风险：V1c 与第一次 JVc 都被已知的 SERIAL_OR_AUDIT_WRITE_FAILURE
  安全中止（驱动停、客户端确认新失能，无危险动作）；usbipd detach/attach
  重置链路后 JVc2 完整跑通（trajectory_error_code=0）。
- 归档：j5_sag_model_20261110.json、j5_compensation_result_20261110.json、
  plans/J5A|J5B|JV|JVc_20261110.json、对应 raw/clients/windows。

## 7. 迭代式静态补偿（J3/J5 残余跟进）

模型前馈在 JV 上把 RMS 降到 0.171°，但 J3 残余 0.283°、J5 残余 0.266°；
原因是 J3 存在姿态/耦合偏置、J5 回差幅度随姿态与方向变化。改用**闭环迭代
补偿**：先跑一次基准，测每个路点残差，按残差修正指令；再跑一次，用第二次
残差再修正（等价于逐路点校准，需要两轮采集；仍是位置前馈，不是转矩 FF）。

新姿态 JZ：基准 [6,9,6,4]，J5 在 -20..25° 内两次换向，11 个路点，未参与
任何训练。结果（9 个有效路点，残差相对期望姿态）：

| 指标 | 基准 | 迭代 1 | 迭代 2 |
|---|---:|---:|---:|
| 总体 RMS（deg） | 0.632 | 0.127 | **0.0775** |
| 最大（deg） | 1.017 | 0.284 | **0.164** |
| J1 最大 | 1.017 | 0.027 | 0.018（-98%） |
| J2 最大 | 0.935 | 0.075 | 0.061（-93%） |
| J3 最大 | 0.261 | 0.186 | **0.142（-46%）** |
| J4 最大 | 0.459 | 0.153 | 0.021（-95%） |
| J5 最大 | 0.355 | 0.284 | **0.164（-54%）** |

- 两轮后 J3/J5 残余明显下降；剩余主要受回差/摩擦幅度与姿态耦合限制
  （J5 指令-实际仍可见 ±0.3° 回差，但相对期望残差已到 0.16° 量级）。
- 代价：每个新工位/路径需先跑一次基准再生成补偿计划（可自动化）；补偿计划
  首末仍绝对零；所有安全门限未动。
- 归档：iter_comp_result_JZ_iter1_20261110.json、
  iter_comp_result_JZ_iter2_20261110.json、plans/JZ|JZc|JZc2_20261110.json、
  windows_JZ|JZc|JZc2.json 及对应 raw/clients。
