# 五轴局部 2° 往返诊断计划

这些是**离线候选计划**，不是自动执行队列表。每个文件只让一个关节相对当前位
`+2°` 或 `-2°`，其余四轴保持相对 0°；往返各 8 s、停留 4 s，总共约 24.5 s。

- `J1_POS/NEG` … `J5_POS/NEG`
- `POS`：先 `+2°` 再返回当前位
- `NEG`：先 `-2°` 再返回当前位；执行前必须确认该方向的实际路径/线缆/限位允许
- 全部使用 `relative_start_deg`，0 表示当前位；不自动放大到 5°/30°/70°
- 标准 arm 会同时使能 J1–J5，不能宣称只使能单轴
- 保持驱动 4° FOLLOWING_ERROR、STOP、5 ms 写期限、3 次 EAGAIN、60 ms 反馈门禁、
  50 ms 周期、限位/温度保护不变

## 建议顺序

1. 支撑、局部净空、STOP/切电可用；
2. 先 `J1_POS`，记录移动/停留误差、五轴响应、请求/反馈估算；
3. 通过后再做 `J1_NEG`，然后依次 J2–J5；
4. 任一轴出现持续漂移、误差接近门限、异常温升/抖动/电流异常即停止扩展；
5. 五轴单轴全部通过后，才考虑低幅双轴/联动；不要用 J5 单轴成功代替整机验收。

未知真实能力/电流/母线数据时，不授予正式调参/扩幅资格；这些计划只用于诊断，不是
1.5 倍裕量验收。
