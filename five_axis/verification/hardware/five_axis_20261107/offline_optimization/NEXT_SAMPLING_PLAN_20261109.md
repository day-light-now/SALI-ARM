# 有符号/多姿态采样计划（2026-11-09）

本文件是**计划**，不是执行授权。不启动 driver/panel、不使能、不运动。

## 目标

用有符号、可辨识、独立验证的数据判断：

1. 静态保持误差是正偏、负偏还是双向波动；
2. 重力/负载是否随多关节姿态变化；
3. 常值高增益、角度调度、受限 FF 的**静态**表现；
4. 动态峰值、过冲、振荡、温升与停止行为。

## 必须记录

每周期：

```text
timestamp, target[5], actual[5], velocity[5], effort[5],
feedback_valid[5], motor_state[5], timeout_count[5],
temperature[5], command_id, control_state
```

以及：

- 模型坐标/电机坐标、`hardware_sign`、零位、减速比、Nm 单位约定；
- 真实电流、母线电压、外部扭矩（若可用）；
- 完整运行/姿态分组 ID，禁止随机拆相邻采样。

## 姿态集（需新授权后执行）

A. **单轴静态保持**：固定其余轴，逐轴 +5/+10/+20/+30/+40°（在限位内）；
   每个姿态保持足够长时间，记录稳定窗口。

B. **反向接近**：先 +40° 再回到 +20°，和直接从 +0° 到 +20°，比较同姿态
   正反向结果。

C. **混合姿态**：至少 3 组不同关节组合（不能全部 `[s,s,s,s,s]`），
   覆盖主要工作区；每组重复 2 次。

D. **跨次运行**：同一姿态集至少两次独立启动/走线。

E. **动态**：慢速和较快两组，记录运动峰值、过冲、settling、速度/振荡、
   温升；不得为了动态测试放宽 4°/STOP 等保护。

## 训练/验证隔离

- 按整组姿态/整次运行拆分训练和验证；
- 单轴、混合、反向、跨次运行分别报告；
- 一维 path-local 拟合只能用于当前路径条件，不声明全工作区泛化；
- 外推直接拒绝。

## FF 实现前置

若使用有符号 FF，必须：

- 有 Nm 和变化率限制；
- 平滑启停；
- 身份/模型/有效域绑定；
- 反馈无效、STOP、失能、故障时立即清理；
- 先在软件/PTY 验证，再另行申请现场实验；
- 仍需真实 allowed output/demand 证据才能谈 1.5× 裕量。

## 准入

- 默认 1800s artifact/evidence 新鲜度；
- 掉电后重新读取 J5 TIMEOUT 和当前证据；
- 大角度入口核对实际部署的保护，不依赖其他工作区未部署候选。
