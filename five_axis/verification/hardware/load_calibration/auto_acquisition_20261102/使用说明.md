# 自动负载补偿采集（J1首轮）

入口：桌面SLAI机械臂控制/03_桌面上位机/自动负载补偿采集.bat。程序打开不连接、不使能，先只读预览路线，再明确启动。

用户当前范围：软件角度J1 −70°～+70°。机械端点为用户确认的当前坐标−80°～+200°；本轮主动缩小范围，目标端点额外留0.5°，为−69.5°～+69.5°。J1最新sign=+1、zero=1.4574273289082171rad，编码器增大为正。旧−1方向记录不能用于本次路线。现有模型参考范围−200°～+80°，本次扫描−70°～+70°位于两者内，没有改模型或零位。

流程：
1. 关闭其他程序串口连接，打开本入口，点“只读预览路线”。四轴必须为新鲜MIT/2000/正常失能；未配置其他轴机械包络，本轮只开放J1。
2. 核对实际起点、计划范围、路段数和预算。起点在范围外则拒绝，不自动回到范围内。预览只读，保存tmp/auto_load_preview/*.json。
3. 机械臂可靠固定、防坠、线缆整段无干涉；J2–J4必须能可靠维持相对姿态，且外部支撑不能分担待标J1的负载或卡住其旋转。不能做到就不启动，不为采样撤去防坠措施。
4. 填工作姿态标签和实际负载，落实四项现场条件后点“明确启动本次J1自动采集”。先在当前位置接管并检查稳定，再按≤10°分段走到下端、正向采样、反向采样、分段返回预览起点。
5. 全程现场观察，异常点停止并保持支撑，必要时切电。暂停/故障不自动续跑；UNKNOWN停止主动查询、锁定入口。不得根据进度自动重置原始范围、时间预算或零位。

速度保留：参考峰值≤0.02rad/s、反馈速度中止1rad/s。10°最小跃度段约16.4秒；末端留到位余量。每个候选点至少稳定等待3秒、最多30秒，完整参考预算约26分钟（以当前只读预览为准），稳定后可提前结束各点等待。首轮不是700点凑数量：约29个双向样本、含中转约42段，实际角度范围和方向覆盖另行验收。

原生MIT：Kp160/Kd5，J1总请求估算门槛8Nm，不是驱动硬限幅；积分负载偏置Ki12、前馈≤2Nm、变化≤0.5Nm/s；只在增益斜坡完成、低速且小误差时学习。原温度、时效、周期、4°跟随误差、四轴FD和新反馈失能确认保留。预览后的零位/sign改变或起点移动超过0.5°会拒绝执行。先生成整个有限路线，不能在执行时随意换目标。

四轴数据：AUTO_LOAD_OBSERVATION同时保存J1–J4姿态、速度、状态、反馈力矩估计、有效控制请求估计、温度和反馈年龄。只使能J1，其他轴失能时的力矩字段明确标为不具备静态拟合资格；移动段也不当纯重力标签。只有到位后的稳定窗口可形成合格J1静态点，记录实测四轴姿态和保持请求估计。要同时获得四轴保持力矩，需要另行验收四轴闭环保持，本版没有悄悄开启。

输出：tmp/auto_load_acquisition/ 下的逐帧JSONL、结果JSON及逐点原子写入的checkpoint.json。中断时已经采到的数据保留，不能自动续跑。只有最终新反馈确认DISABLED，合格点才可追加verification/hardware/load_calibration/records.jsonl；状态未知时仅保留待核数据，不入合格档案。

不读取仿真重量、CAD质量或重力模型；真实保持输入中仍混有静摩擦、线缆及外力。后续须结合正反向同姿态数据与其他工作姿态，拟合并做留出验证；不把一次J1扫描称为全臂重力辨识完成，不自动启用补偿表。

来源复用：腕部wrist_mapping_lab/run700.py、sensorless700.py的有限路线、稳定窗口、逐条日志和停止确认思路。没有复用腕部舵机/绳索/张力参数，没有调用腕部硬件。
