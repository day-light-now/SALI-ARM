# 四轴重力补偿准备

更新（2026-10-08）：已从 CAD 提取暂定质量/重心，并按官方电机总重修正。估算页可联动已有四轴 fake 位置仿真，根据反馈更新静态保持力矩；无串口、CAN 或实机力矩输出。肩部安装重力暂按用户截图设为 base_link +Y 朝下，正式 URDF 未修改。下文待补数据清单保留为标定检查项，不表示暂定模型尚不存在。

## 已完成的软件

- `gravity_model.py` 从正式四轴 URDF 读取轴、连接坐标和限位，用质量和重心计算维持当前姿态所需的关节力矩。输出单位 N·m，符号遵循 URDF，而不是电机编码器。
- `test_gravity_model.py` 的 5 项测试通过：势能数值梯度、竖直 J1 零力矩、质量线性缩放、零重力和非法输入拒绝。测试质量和重心为合成数据，不是 SLAI 实物参数。
- `audit_cad_mass.py` 只读提取正确 SolidWorks 总装的逐零件质量、重心、材料和惯量，并按 link 合并。检测配置差异、材料缺失和电机导入模型风险。

## 需要用户确认的物理数据

1. 金属、打印件的实际材料；打印件的填充率或称重质量。
2. J10010L、J8009P 和 link4 上现有 J4340 的准确型号/实测质量。导入电机壳体可能是空壳或简化实心体，不能默认 CAD 质量准确。
3. 线缆、连接件和末端负载是否计入；即使 J5 不运动，其安装在 link4 上的质量也参与重力计算。
4. 底座实际安装方向，用于确定 base_link 中的重力向量。

仅称重不能自动确认重心和惯量；均匀缩放或近似需要单独记录假设。静态重力补偿主要用质量和重心，惯量则是后续动态补偿需要。

## 开发命令

从 Windows 工作区运行：

```powershell
python slaihand_ros2_ws/verification/audit_cad_mass.py
python slaihand_ros2_ws/verification/test_gravity_model.py
```

审计结果保存到 `verification/gravity_preparation/cad_mass_audit.json`，标记为未校准 CAD 数据。离线计算入口要求显式提供四轴角度、base_link 中的重力向量，以及 `--allow-provisional`；没有质量文件时不可计算实物力矩。

后续再做：核实逐 link 参数 → 写入正式 URDF 的 inertial 并验证 → 离线姿态/力矩扫描 → 动力学模拟 → 电机方向/零位与力矩模式校准 → 限流、急停和低增益实机测试。

现有 OpenArm fake 驱动仅模拟位置跟随，尚未接入力矩控制。当前工作不等于已完成可拖动示教、实机重力补偿或动力学仿真。
