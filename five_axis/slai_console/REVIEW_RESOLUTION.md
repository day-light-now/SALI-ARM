## 已处理

- P1-1：断开超时不再向 Qt 槽抛异常；保留 worker 并回滚下拉框，实际模式不切换。关闭窗口遇到未退出线程也会保留窗口。假 worker 回归覆盖。
- P1-2：Context 默认断开、未使能、过期；仿真读取真实模型状态及更新时钟，实机读取真实线程和四轴反馈。仍优先无条件拒绝实机输出。补默认拒绝与仿真反馈过期检查。
- P1-3：轨迹票据绑定完整不可变路点与每段时长；网关检查所有路点，审计保存整条轨迹。后续实际执行使用票据内的参数；底层 adapter 拒绝覆盖执行中的轨迹。补篡改后续路点、重复消费、非法后续路点、busy 覆盖测试。
- P1-4：补 ID 选择器的禁用态样式；未预览时主执行按钮灰色，新增逻辑禁用断言。
- P1-5：遥测进入 UI 前检查必要字段、范围与报文长度；异常样本清空反馈。tick 外层降级处理、暂停仿真、清空显示并限频记录错误。
- P1-6：实机只读禁用滑条和角度输入，不创建运动票据或幽灵预览；取消预览按当前模式读取有效姿态。
- P2-1/2：按 J5 行语义涂灰，不再错误涂灰第五条日志/路点；内部状态名改中文。
- P2-3：动力学下拉框与真实 Simulation.mode 同步；停止的语义仍是进入弹簧保持。
- P2-5/6：修正镜头包围范围；扩大模型视口；概览/零位表固定五行高度；压缩路点表及关节摘要区域。
- P2-7：路点只取 qpos[:4]。模型仍显式要求 nq=4，J5 未来必须连同模型和协议验收后扩展。
- P2-10：raw16 直接取八字节原始 payload 的第 1、2 字节，不再反算。
- P2-11：增加窗口级 Esc 快捷键。
- 增加 GL 专用线程，只保留最新渲染请求，避免模型渲染阻塞滑条。
- 增加窗口化启动错误日志和可见错误提示，VBS 内容使用 ASCII/ChrW 避免中文编码导致静默失败。

## 保留的取舍与边界

- 概览、软件零位、日志页优先表格，不显示 3D；关节、轨迹、动力学显示真实模型。
- 预览模型位置校验最终仍由网关执行，UI 输入范围受同一份 LIMITS 约束；不对非法目标静默裁剪。
- 2000 行审计视图目前重建表格，适合低频 UI 日志；真实 CAN 高频帧写另一个文件，不逐帧进入 UI 日志。后续需要高频 UI 审计再换增量模型。
- 网关先记“接受”，adapter 成功后开始仿真。当前调用同步、无控制线程竞争，adapter 独立再校验；后续硬件输出接口必须引入明确的接收/发送/确认三阶段状态，不能沿用“接受即已发送”的语义。
- 未实现长按点动、文件回放、碰撞检查、零位草稿自动应用、实机运动。页面和说明均按实际能力标注。

## 证据
