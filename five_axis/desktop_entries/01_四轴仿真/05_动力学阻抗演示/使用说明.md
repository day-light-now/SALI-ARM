# MuJoCo 控制实验室（仅仿真）

双击“启动MuJoCo控制实验室.bat”，出现原生控制面板和 MuJoCo 3D 窗口，不依赖网页、ROS 或 CAN；与原 RViz/8767 相互独立。

点击“自动表演”观看约 18 秒对比，也可手动选择：

1. 无补偿：保留阻尼，重力使手臂下垂。
2. 补偿：重力前馈 + 阻尼，无位置弹簧；施加外力后让开，在新位置附近停止。
3. 弹簧：重力前馈 + 关节 PD；推开后回到目标。

启动时为四轴零位 [0°,0°,0°,0°]，默认弹簧 + 重力补偿保持零位。“重置到零位”清除运动和外力并回到零位（仿真状态重置，不是实机回零轨迹）。单独点击“进入演示姿态”才切到 [25°,65°,0°,-25°]；自动表演也会切到这个姿态进行对比，结束后保持演示姿态。这不改变关节零位。

上下推按钮在 link4 重心施加 8 N、0.4 秒的世界 Z 方向外力。可把当前姿态设为新弹簧目标。关闭控制面板可退出两窗口。

控制律：τ = g(q) + Kp(q目标−q) − Kd·q速度；补偿模式 Kp=0，无补偿模式去掉 g(q)。重力项通过零速度 MuJoCo 模型计算，与独立势能/力矩算法交叉核对。此版是关节阻抗概念演示，不是末端笛卡尔阻抗或 JEP 论文复现，也不是 OpenArm 官方完整控制移植。

模型源：最新正式四轴 URDF（J2 正方向及 J3/J4 轴已纠正）与 provisional_gravity.json。肩部安装 Rx(−90°)，底座 +Y 朝下。J5 不运动，其电机重量在 link4 内。惯量/重心与电机转子定子分配暂定，摩擦未辨识，无线缆/负载，无碰撞或接触验证。

演示增益、阻尼和力矩上限是仿真假设，不是厂商参数；正式 URDF 的 effort=1 占位值未当作真实力矩额定值。MuJoCo 关节限位是软约束，瞬时可能轻微越界，不能当作真实机械限位保证。禁止将这些参数直接用于实机。
