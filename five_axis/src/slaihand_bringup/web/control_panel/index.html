开始后托住机械臂等待 3 秒渐入；持续时间从渐入完成后计时。停止后确认失能再落盘。回放默认速度比例 0.5，峰值参考速度上限 1 rad/s，长记录降速回放仍需满足会话时间预算。

这两项用于自由拖动与示教记录，下次启动时固定本次设置。Kd 越小阻尼越轻，0 表示零阻尼。启动后以驱动回执为准，结束时承接重量。

    单轴标定流程（零位 → 正方向 → 下限 → 上限）

    统一选择 J1–J5 中的一轴，只记录人工读数与候选；不使能、不写电机零位、不生成正式标定记录。停止 / 身份变化 / 反馈失效 / UNKNOWN 都会作废序列。
    1. 选择轴并开始会话；服务端确认运行身份、全部轴未使能、该轴反馈新鲜有效。
    2. 保持机械臂静止，采集零位读数（模型角度，不是电机零位写入）。
    3. 人工把该轴向正方向缓慢移动约 10°，采集正方向移动；只得到候选符号，不写 mapping。
    4. 人工移动到下限与上限端点分别采集；上下限必须有限且严格有序。

    本流程只在面板存档写入非正式 JSON 审计；不会写 hardware_mapping.yaml、URDF 或电机零位，也不会发任何运动命令。候选符号/区间必须现场复核后按授权路径手工写入。

    当前位置静态采样（重力标定）

    单一所有者有限操作：位置保持 → 撤手确认 → 静态窗口 → 停止并保存；不修改参数、不写质量档案。
    1. 结束自由拖动/示教，等待新失能确认，再用“软件复位”进入未使能。
    2. 预览冻结当前实际姿态，核对角度、运行身份、Kp/Kd、α 基线与有限时间。
    3. 确认后启动普通位置保持；页面显示“保持已就绪”后托稳并缓慢撤手。
    4. 防坠支撑不承重后勾选并点击“已撤手，开始采样”；客户端采集静态窗口。
    5. 停止优先：先全轴停止并确认新失能，再保存原始数据与只读残差。
